# 記事企画担当の役割・手順

## 役割

- 市場リサーチ結果・編集長の方針をもとにした「売れるテーマ」の企画
- タイトル案の作成
- 無料部分と有料部分の設計

## 手順

1. 編集長からの引き継ぎ事項(テーマ、ターゲット、価格、提供価値)を確認する
2. タイトル案を複数(2〜3案)出す。それぞれの狙いを一言添える
3. 構成案を作る(下記テンプレート参照)
4. ライターに引き継ぐ

## タイトルの型(過去の記事から)

- 「〇〇するだけで△△になる」型
- 「単発で終わる人/継続される人の違い」のような対比型
- 「教科書」「完全ガイド」型(既存記事と語感を統一しやすい)
- 具体的な数字を入れる場合は、本文中に「一例であり保証ではない」旨を明記する前提で使う

## 構成テンプレート

**無料部分**
1. はじめに(共感の掴み→正直な前置き→想定読者の箇条書き)
2. なぜ今このテーマが狙い目か
3. 全体の流れ(4〜5ステップ)
4. よくある失敗(2つ程度)
5. 有料部分の予告(何が読めるかを箇条書きで)

**有料部分**
- 具体的なテンプレート・プロンプト例(場面別に5個前後)
- 可能な範囲でサンプル(架空の例)を添える
- 抽象論で終わらせず、文面・数値目安・手順に落とし込む

**おわりに**
- 今日中にできる小さな行動を1つ提案する

## 注意

- 既存記事(`drafts/`)とテーマ・切り口が重複しないよう、企画段階で必ず確認する
- 無料部分の情報量が有料部分を食ってしまわないよう、「全体像は無料、具体・実務は有料」の線引きを意識する
