## はじめに

コーチ、士業、講師業など個人で活動している人のセミナー・オンライン講座の告知ページを見て、「内容は良さそうなのに、文章だけでは魅力が伝わりきっていない」と感じたことはないでしょうか。デザインは無料テンプレートで整っているのに、見出しが「〇〇セミナーのご案内」だけで終わっていたり、参加するとどう変われるのかが本文のどこにも書かれていなかったり。作っている本人が手を抜いているわけではなく、集客の合間に自分でページ文章まで書く時間が取れない、というのが実情であることが少なくありません。

正直に言うと、LP(ランディングページ)コピー代行というと「凄腕のセールスライターでないとできない」と思われがちです。ですが実際に個人で活動する講師・コーチ側が困っているのは、高度なセールス理論よりも、「自分の講座の良さを、参加を迷っている人にどんな言葉で伝えればいいかわからない」という、もっと手前の部分であることが少なくありません。この記事は、AIを使ってLPの構成・文章の下書きを作り、依頼主へのヒアリングをもとに仕上げる形で、セミナー・講座の集客ページコピー作成を副業として請け負うための考え方と手順をまとめたものです。

想定している読者は、次のような会社員です。

- デザインやコーディングのスキルはなくても、文章で相手を動かすことに興味がある
- ライティングやSNS運用代行に加えて、もう一つ別の切り口の副業を持ちたい
- 副業に使える時間は平日の隙間時間と土日程度

※タイトルの内容は取り組み方の一例です。案件の獲得や収入を保証するものではありません。

## なぜ今、「LPの文章だけ」でも副業になりうるのか

コーチ・士業・オンライン講師のような個人事業主が、ペライチやSTORES、Googleフォームなどを使って自分でセミナー集客ページを作れる環境は、この数年でかなり身近になりました。一方で、LP制作を代理店やデザイナーに丸ごと依頼すると、デザイン込みで数万円〜数十万円かかることが一般的に言われており、実績がまだ少ない個人にとっては気軽に外注しづらい金額です。

ここに、LPの「文章部分」だけを請け負う余地があります。ページのデザイン・公開作業は依頼主自身がペライチ等のテンプレートで行い、「参加したくなる文章をどう書くか」という原稿部分だけを外部に依頼する、という分業です。AIを使えば、構成案・見出し・本文の下書き自体は短時間で複数パターン作れるため、ゼロから毎回考えるより時間を圧縮できる可能性があります。

一方で、AIがそのまま出すLP文章は、どの講座にも当てはまるような一般論になりがちで、その講師・コーチならではの伝え方や、参加者が本当に気にしているポイントが抜けやすくなります。だからこそ、依頼主にヒアリングして文章に反映できる人には、まだ入り込む余地があると考えられます。

## 全体の流れ(5ステップ)

セミナー・講座LPコピー代行の副業を始めてから案件をこなせるようになるまでの流れは、大きく次の5ステップです。

1. **対象ジャンルを絞る**:コーチング・士業・語学・ハンドメイド講座など、自分が理解しやすいジャンルを1〜2つ選ぶ
2. **LPの型を知る**:申し込みにつながりやすいセミナーLPに共通する基本の構成要素を把握する
3. **AIで下書きを量産**:プロンプトを使って構成案・見出し・本文の下書きを複数パターン作る
4. **依頼主の実情に仕上げる**:一般論を、その講師・コーチならではの実績・実例に置き換える
5. **提案・納品・改善**:試作の構成案を見せて提案し、申し込み状況を聞きながら次の文章に活かす

## よくある失敗

具体的な手順に入る前に、つまずきやすいポイントを2つ紹介します。

**失敗1:効果・成果を裏付けなく断定して書いてしまう**
特にコーチング・士業・健康関連の講座は、「必ず結果が出ます」「絶対に人生が変わります」のような効果を保証する表現を使うと、景品表示法・特定商取引法などに触れる可能性があります。代行者が良かれと思って盛った表現が、依頼主側の法的リスクになりかねません。効果・実績に関わる表現は、依頼主が根拠を持って確認できる内容にとどめ、判断に迷う場合は「その表現は避けましょう」と提案することが前提になります。

**失敗2:AIの出力をそのまま貼り付けてしまう**
AIが作ったLP文章をそのまま使うと、どの講座のページを読んでも似たような言い回しになり、その講師・コーチならではの魅力が伝わりにくくなります。下書きは「たたき台」として使い、依頼主の実際の実績・受講者の声・人柄が伝わるエピソードなど、その講座ならではの情報を一つでも加える一手間が必要です。

## 場面別のLPコピープロンプト

以下のプロンプト内の【 】部分は、実際の依頼主からヒアリングした内容に合わせてご自身で書き換えてご利用ください。文例サンプルはあくまで型のイメージをつかむための架空の例です。実際のLPでは、依頼主から確認が取れた事実(実績・受講者の声・資格など)のみを反映してください。

### パターン1:LP全体の構成案(見出し)を作るプロンプト

```
以下の情報をもとに、セミナー・オンライン講座の集客ページ(LP)の
構成案を、見出しレベルで作ってください。
読者が「自分に関係がある」と感じる悩みの提示から始め、
講座の内容、参加後にイメージできる変化、申し込みへの導線という
流れになるようにしてください。効果を保証する表現は使わないでください。
講座名:【講座名】
対象者:【想定する参加者像】
講座で扱う内容:【店舗・講師から確認した内容】
講師の実績・資格:【確認できている事実のみ】
開催形式・料金:【店舗から確認した情報】
```

**構成案サンプル(架空の例・オンライン家計相談講座)**
> 1. 見出し:「家計簿は続くのに、貯金が増えない」その理由、3分でわかります
> 2. こんな方におすすめ(悩みの箇条書き)
> 3. この講座で扱う内容(3つのポイント)
> 4. 講師紹介(資格・実績)
> 5. 参加者からの声
> 6. よくある質問
> 7. 開催概要・お申し込み

### パターン2:悩み・共感を誘うオープニング文を作るプロンプト

```
以下の情報をもとに、LPの冒頭で使う「共感を誘う導入文」を
300字程度で作成してください。読者の悩みに寄り添いつつ、
不安を煽りすぎる表現や、必ず解決すると断定する表現は避けてください。
対象者:【想定する参加者像】
よくある悩み:【依頼主が聞いている参加者の悩み】
講座で得られること:【店舗・講師から確認した内容】
```

**文例サンプル(架空の例・オンライン家計相談講座)**
> 毎月の家計簿はつけているのに、なぜか貯金が増えない。そんなモヤモヤを抱えたまま、今月もなんとなく過ごしていないでしょうか。原因は「頑張り不足」ではなく、多くの場合「振り返り方」にあります。この講座では、家計簿の数字をどう見て、どこから手をつければいいかを、一緒に整理していきます。

### パターン3:参加前後のイメージを伝えるプロンプト

```
以下の情報をもとに、この講座に参加することで参加者がどう変化しうるかを
イメージしやすい形で3つ挙げてください。個人の実体験談として断定せず、
「〇〇に取り組みやすくなります」のような、一般的に期待できる変化として
表現してください。
講座の内容:【店舗・講師から確認した内容】
参加者が抱えやすい悩み:【依頼主が聞いている悩み】
```

**文例サンプル(架空の例・オンライン家計相談講座)**
> ・家計簿の数字をどこから見直せばいいか、優先順位をつけやすくなります
> ・固定費の見直しポイントを、自分の家計に当てはめて考えられるようになります
> ・「なんとなく不安」だった家計の状態を、数字で把握できるようになります
> ※効果には個人差があり、上記は取り組み方の一例です。成果を保証するものではありません。

### パターン4:よくある質問(FAQ)・不安払拭パートを作るプロンプト

```
以下の講座について、申し込みを迷っている人が気にしそうな質問を
5つ想定し、それぞれに対する回答をLPに追加できる形で作成してください。
講師・店舗から確認が取れていない内容は、質問として保留にし、
勝手に回答を作らないでください。
講座名:【講座名】
講座の情報:【店舗・講師からヒアリングした情報】
```

**文例サンプル(架空の例・オンライン家計相談講座)**
> Q. 家計簿アプリを使っていなくても参加できますか? → A. 紙の家計簿や手書きのメモでも参加いただけます。当日は数字の整理の仕方を一緒に確認します。
> Q. 録画での視聴は可能ですか? → A. 録画の可否は開催回によって異なります。詳しくはお申し込みページの開催概要をご確認ください。

### パターン5:申し込みボタン周りの後押し文(CTA)を作るプロンプト

```
以下の情報をもとに、LPの申し込みボタン付近に置く後押し文を
100字程度で作成してください。緊急性を煽りすぎる表現(「今すぐ」の
連呼、残りわずかの誇張等、事実と異なる可能性のある煽り)は避け、
参加のハードルを下げる情報を優先してください。
講座名:【講座名】
定員・締切:【店舗から確認した事実のみ】
返金・キャンセル対応:【店舗の実際の対応方針】
```

**文例サンプル(架空の例・オンライン家計相談講座)**
> まずは1回、話を聞いてみるだけでも大丈夫です。当日の内容が合わないと感じた場合のキャンセルについても、お気軽にお問い合わせください。

これらの文章はあくまで「たたき台」です。特に実績・資格・定員・返金対応に関わる部分は、依頼主側から確認が取れた内容のみを反映し、確認が取れていない項目は断定せずに保留にしてください。

## 効果・実績表現で必ず気をつけたい注意点

セミナー・講座のLPは、参加を検討している人が申し込みを判断する材料であり、実際の内容と異なる期待を持たせないことがLP作成の基本ルールとされています。代行者として、次の点は特に意識してください。

- **成果・効果を保証する表現を使わない**:「必ず結果が出ます」「絶対に人生が変わります」のような、効果を断定・保証する表現は避ける(コーチング・士業・美容・健康系の講座は景品表示法などの規制対象になりうることを念頭に置く)
- **特定商取引法上の表示が必要な講座かどうかを依頼主に確認する**:有料の講座・セミナーは、事業者名や連絡先、返金対応などの表示が法律上必要になる場合があります。代行者が判断せず、依頼主自身に確認・表示してもらうよう促してください
- **実績・参加者の声・資格などは、依頼主側が確認した内容のみを記載する**:代行者の推測や「おそらくこうだろう」という想像で埋めない
- **希少性・緊急性を誇張しない**:「残りわずか」「今だけ」を事実と異なる形で使わない
- **判断に迷う表現は、掲載前に依頼主自身の確認を挟む**:効果・実績や法規制に関わりそうな一文は、代行者だけで判断せず、必要であれば依頼主側で最終確認してもらう

これらは参加者との信頼関係を保つためだけでなく、代行者自身が思わぬトラブルに巻き込まれないためにも重要な確認事項です。

## 案件の探し方・提案文テンプレート

セミナー・講座LPコピー代行の案件は、大きく分けて「クラウドソーシング」と「個人講師・コーチへの直接提案」の2つの経路があります。

**クラウドソーシング**
クラウドワークス、ランサーズなどで「LPライティング」「セミナー集客ページ 文章」「セールスコピー」といったキーワードで検索すると、文章作成のみを募集している案件が見つかることがあります。募集内容をよく読み、文章作成だけか、デザイン・コーディングまで含むかを事前に確認してください。

**個人講師・コーチへの直接提案**
X(旧Twitter)やInstagramでセミナー・講座を告知している個人講師・コーチに、直接提案する方法もあります。実際の告知ページを見て、文章を改善するとどう印象が変わりそうかを具体的に伝えることが、提案の説得力につながります。

### 提案文テンプレート例(実績がまだない場合)

```
はじめまして。【ジャンル】の講座・セミナーの集客ページ文章作成の
ご提案でご連絡いたしました。
拝見した告知ページから、【気づいた点を一言】と感じました。
講座の魅力がより伝わる文章の作成でお力になれればと考えております。
実績・効果に関わる記載は毎回ご確認いただいたうえで
作成する形を想定しております。
まずは冒頭部分だけでも無料でお見せすることもできますので、
よろしければご検討ください。
```

### 提案文テンプレート例(実績が数件できた場合)

```
セミナー・講座の集客ページ文章作成を承っております
【氏名/屋号】と申します。
これまで【ジャンル】の集客ページ文章を【件数】件担当し、
実績・効果に関わる記載は毎回事前確認をいただく形で運用しております。
拝見した告知ページから【気づいた点】と感じ、ご連絡いたしました。
新しい講座を開催される際の集客ページ文章のご相談も可能ですので、
よろしければご検討ください。
```

提案の際は、いきなり売り込むのではなく、「冒頭部分だけ無料で見せる」など、依頼主側が判断しやすい材料を示すと、検討してもらいやすくなります。ただしサンプルを何点も無償で作り続けることは避け、最初の1件程度にとどめておくのが現実的です。

## 単価の考え方

セミナー・講座LPコピー代行の相場は、ページのボリューム・ヒアリングの手間・構成案から仕上げまで対応する範囲によって幅があります(※一般的な相場感に基づく参考値で、案件により変動します)。目安として次のような段階を意識すると進めやすくなります。

- **実績作り期**:構成案+本文一式を、相場よりやや低めの単価で数件引き受け、依頼主へのヒアリングの進め方に慣れる
- **実績提示期**:対応してきたジャンル・件数を提案文に添えられるようになった段階で、1本あたりの単価を提案する
- **専門特化期**:特定ジャンル(コーチング専門、士業専門など)に絞り、そのジャンル特有の参加者が気にするポイント・LPの型を増やすことで、単価交渉の材料を厚くする

単価交渉を通しやすくするために、次の点も意識してください。

- 対応してきたジャンル・件数の実績を、守秘義務に配慮した範囲で伝える
- 修正依頼・表現の指摘には、依頼主の意図を汲み取ったうえで丁寧に対応する
- 値上げの相談は、対応件数や運用実績が見えてきたタイミングで、「継続的に集客ページを改善していくための提案」として伝える
