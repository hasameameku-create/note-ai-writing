## はじめに

CAMPFIREやMakuake、GREENFUNDINGなどのクラウドファンディングサイトを眺めていて、商品やアイデア自体はおもしろいのに、プロジェクトページの文章だけが「スペック説明」で終わっていて、作り手の想いがほとんど伝わってこないページを見かけたことはないでしょうか。写真やリターン(支援者への特典)の設計はしっかりしているのに、肝心の「なぜこれを作ろうと思ったのか」「支援することでどんな未来につながるのか」という部分が、箇条書き数行で済まされている。そんなページは少なくありません。

正直に言うと、クラウドファンディングの文章代行というと「有名な代行会社に頼む高額なコンサルサービス」のイメージが強いかもしれません。実際、ページ制作からSNS拡散戦略まで一括で請け負う代行サービスには、数十万円規模の料金がかかるケースもあるようです。ですが、個人や小規模チームで初めてクラウドファンディングに挑戦する人の多くが本当に困っているのは、そこまで大掛かりな話ではなく、「自分の想いを、支援したくなる文章にうまく言葉にできない」という、もっと手前の部分であることが少なくありません。この記事は、AIを使ってプロジェクトページの文章の下書きを作り、作り手本人への確認を通じて事実に基づいた形に仕上げていく、「文章パートだけ」のクラウドファンディング代行を副業として始めるための考え方と手順をまとめたものです。

想定している読者は、次のような会社員です。

- クラウドファンディングの実務(審査対応・入金・税務周り等)には関わらず、文章パートだけで力になりたい
- ライティングやSNS運用代行に加えて、もう一つ別の切り口の副業を持ちたい
- 副業に使える時間は平日の隙間時間と土日程度

※タイトルの内容は取り組み方の一例です。案件の獲得や収入を保証するものではありません。

## なぜ今、「クラファンの文章パート」だけでも副業になりうるのか

クラウドファンディングは、以前のような大規模プロジェクトだけでなく、個人の作家・小さな飲食店・地域の工房など、小規模な作り手が「新商品の先行予約」や「お店の改装資金集め」といった目的で挑戦するケースが増えてきています。こうした作り手は、商品やサービスそのものには強いこだわりとストーリーを持っている一方で、プロジェクトページという「長文の読み物」を一から書き上げることには慣れていないことが多く、ここに文章面での支援の余地があります。

ページ制作会社に丸ごと依頼するほどの予算はないけれど、自分だけでは文章の構成や言葉選びに自信が持てない。そうした作り手にとって、「ページデザインや審査対応は自分たちで行い、文章の下書きと整えだけを依頼する」という分業は、現実的な選択肢になり得ます。AIを使えば、プロジェクトストーリーやリターン説明文、想定FAQといった複数パートの下書きを、ヒアリング内容をもとに短時間で作成できるため、ゼロから毎回文章構成を考えるより時間を圧縮できる可能性があります。

一方で、AIがそのまま出す文章は、どの作り手にも当てはまりそうな一般的な「想いの表現」になりがちで、その人・そのプロジェクトならではの背景や熱量が抜け落ちやすいという弱点があります。さらにクラウドファンディングには、支援者に実現可能性を誤解させない書き方や、景品表示法の考え方に沿った表現といった特有の注意点もあります。だからこそ、作り手本人に丁寧にヒアリングし、確認が取れた事実とその人の言葉を文章に落とし込める人には、まだ入り込む余地があると考えられます。

## 全体の流れ(5ステップ)

クラウドファンディング文章代行の副業を始めてから案件をこなせるようになるまでの流れは、大きく次の5ステップです。

1. **対象ジャンルを絞る**:ものづくり系・飲食系・地域活性化系など、自分が興味を持ちやすいジャンルを1〜2つ選ぶ
2. **クラファンページの型を知る**:支援につながりやすいプロジェクトページに共通する基本の構成要素を把握する
3. **ヒアリングシートを作る**:作り手の想い・経緯・リターン内容を聞き出すための質問項目を用意する
4. **AIで下書きを量産**:プロンプトを使ってパート別(ストーリー・リターン説明・FAQ等)に文章下書きを作る
5. **確認・仕上げ・提案**:作り手本人に内容を確認してもらい、事実に基づいた形に仕上げたうえで提案・納品する

## よくある失敗

具体的な手順に入る前に、つまずきやすいポイントを2つ紹介します。

**失敗1:作り手の想いやエピソードを、代行者の想像で「盛って」書いてしまう**
プロジェクトストーリーは一人称で書かれることが多いため、代行者が「こう書いた方が感動的だろう」と想像で経験や心境を書き足してしまうと、作り手本人の実際の想いとズレた文章になりかねません。クラウドファンディングのストーリーは、支援者が「この人を応援したい」と思う最大の決め手になる部分なので、想像で補うのではなく、必ず本人への確認を通じて得た言葉・事実だけを使うことが前提になります。

**失敗2:実現可能性があいまいな表現で、支援者に過度な期待を持たせてしまう**
「必ず実現します」「絶対にお届けします」といった断定表現は、製造や開発に不確定要素が伴うクラウドファンディングの性質上、実際にスケジュールが遅れたり仕様変更が生じたりした場合に、支援者との深刻なトラブルにつながりかねません。進捗や納期に関わる表現は、作り手と一緒に「言い切れる部分」と「まだ確定していない部分」を整理したうえで書く必要があります。

## パート別の文章プロンプトと文例サンプル

以下のプロンプト内の【 】部分は、実際に作り手へのヒアリングで得た情報に合わせてご自身で書き換えてご利用ください。文例サンプルはあくまで型のイメージをつかむための架空の例であり、実在のプロジェクトや作り手の体験談ではありません。実際の文章では、ヒアリングで確認が取れた事実・本人の言葉のみを反映してください。

### パターン1:プロジェクトストーリーの下書きプロンプト

```
以下のヒアリング内容をもとに、クラウドファンディングの
プロジェクトストーリーの下書きを600字程度で作成してください。
一人称視点で、きっかけ・込めた想い・実現したい未来の順に
構成してください。ヒアリング内容にない体験や心境は
創作しないでください。断定的な「必ず」「絶対に」等の
表現は使わないでください。
きっかけ:【ヒアリングで確認した情報】
込めた想い:【ヒアリングで確認した情報】
実現したい未来:【ヒアリングで確認した情報】
```

**文例サンプル(架空の例・焼き菓子店の新商品プロジェクト)**
> 「このまちで長く愛されるお菓子を作りたい」という想いから、今回のプロジェクトを立ち上げました。地元の素材を使った焼き菓子を試作する中で、普段お店に来てくださるお客様から「もっと日持ちするお土産用のものが欲しい」という声をいただいたことが、直接のきっかけです。今回のクラウドファンディングでは、試作を重ねてきたレシピを商品化するための製造ロット分の材料費・パッケージ費用にご支援をお願いしたいと考えています。

```
以下のリターン情報をもとに、支援者が内容をイメージしやすい

提供時期・数量に不確定要素がある場合は、断定せず

リターン内容:【ヒアリングで確認した情報】

**文例サンプル(架空の例・5,000円の焼き菓子セットリターン)**

**文例サンプル(架空の例・一部抜粋)**

```

**文例サンプル(架空の例・1パターン目)**

これらの文章はあくまで「たたき台」です。特にストーリー内の体験・心境、リターンの提供時期、進捗報告の内容に関わる部分は、必ず作り手本人への確認を経てから使用し、確認が取れていない内容は断定せず保留にしてください。

## クラウドファンディングで必ず気をつけたい表現上の注意点

クラウドファンディングの文章には、一般的な販促文以上に気をつけるべき点があります。代行者として、次の点は特に意識してください。

- **実現可能性が不確かな内容を、断定的に書かない**:「必ず実現します」「絶対にお届けします」といった表現は避け、確定している事実と、まだ不確定な見込みを分けて書く
- **商品・サービスの効果や品質について、実際より著しく優れているかのような表示をしない**:景品表示法上の「優良誤認」につながりかねない誇張表現は避け、確認できた事実のみを書く
- **提供時期・数量などの条件は、代行者の推測で書かない**:必ず作り手側から提供された情報をそのまま使う
- **一人称のストーリー・体験談は、本人への確認なしに創作・誇張しない**:感動的な文章にしたい気持ちがあっても、事実と異なる心境・経緯を加えない
- **判断に迷う表現・法令に関わりそうな一文は、掲載前に作り手自身やプラットフォームの審査担当に確認を挟む**:代行者だけで景品表示法や特定商取引法上の判断をせず、必要であれば専門家への確認を作り手に促す

これらは支援者との信頼関係を保つためだけでなく、代行者自身が思わぬトラブルに巻き込まれないためにも重要な確認事項です。

## 案件の探し方・提案文テンプレート

クラウドファンディング文章代行の案件は、大きく分けて「クラウドソーシング」と「個人の作り手への直接提案」の2つの経路があります。

**クラウドソーシング**
クラウドワークス、ランサーズ、ココナラなどで「クラウドファンディング 文章」「クラファン ライティング」といったキーワードで検索すると、文章作成のみを募集している案件が見つかることがあります。募集内容をよく読み、文章作成だけか、ページ全体のデザインや戦略立案まで含むかを事前に確認してください。

**個人の作り手への直接提案**
CAMPFIREやMakuakeで、商品やアイデアは魅力的なのに文章が設備・スペックの羅列だけで終わっているプロジェクトページを見つけ、公開されている連絡先(SNS等)から直接提案する方法もあります。実際のページを見て、文章をどう改善できそうかを具体的に伝えることが、提案の説得力につながります。

### 提案文テンプレート例(実績がまだない場合)

```
はじめまして。クラウドファンディングのプロジェクトページ
文章作成のご提案でご連絡いたしました。
公開されているプロジェクトページを拝見し、
【気づいた点を一言】と感じました。製造や審査対応は
そちらにお任せし、ストーリーやリターン説明文などの
文章パートだけお力になれればと考えております。
よろしければ、まず概要だけでもお聞かせいただけますでしょうか。
```

### 提案文テンプレート例(実績が数件できた場合)

```
クラウドファンディングの文章作成を承っております
【氏名/屋号】と申します。これまで【ジャンル】の
プロジェクトを【件数】件担当し、ストーリーやリターン説明の
内容は毎回ご本人に確認いただく形で運用しております。
公開されているプロジェクトページを拝見し【気づいた点】と
感じ、ご連絡いたしました。よろしければご相談だけでも
承れますと幸いです。
```

提案の際は、いきなり売り込むのではなく、「まず概要を聞かせてほしい」など、相手が判断しやすい材料を示すと、検討してもらいやすくなります。

## 単価の考え方

クラウドファンディング文章代行の単価は、担当するパートの範囲(ストーリーのみか、FAQ・進捗報告まで含むか)やヒアリングの手間によって幅があります(※クラウドソーシングサイトで公開されている募集内容をもとにした参考値で、案件により変動します。文章パートのみの簡易な依頼は1件あたり数千円程度、ヒアリングから複数パートの文章一式まで含むものは1プロジェクトあたり数万円程度とされることもあるようです)。目安として次のような段階を意識すると進めやすくなります。

- **実績作り期**:月数件、相場よりやや低めの単価で引き受け、ヒアリングから文章化までの進め方に慣れる
- **実績提示期**:担当してきたジャンル・件数を提案文に添えられるようになった段階で、1プロジェクトあたりの単価を提案する
- **専門特化期**:特定のジャンル(ものづくり系専門、飲食系専門など)に絞り、そのジャンル特有の支援者が気にするポイント・文章の型を増やすことで、単価交渉の材料を厚くする

単価交渉を通しやすくするために、次の点も意識してください。

- 担当してきたジャンル・件数の実績を、守秘義務に配慮した範囲で伝える
- 修正依頼・表現の指摘には、作り手の意図を汲み取ったうえで丁寧に対応する
- 値上げの相談は、対応件数や運用実績が見えてきたタイミングで、「支援につながる文章を継続的に作っていくための提案」として伝える
