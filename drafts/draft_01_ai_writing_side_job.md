# ChatGPTで月3万円。会社員が土日だけで始めるAIライティング副業の教科書

---

## はじめに

Xのタイムラインを開けば「AIで稼ぐ」系の投稿が流れてくる。ChatGPTを開いてはみたものの、結局いつもの業務連絡を打ち込んで終わる。そんな週末を過ごしていないでしょうか。

正直に言うと、AIツールを触っただけで収入が生まれることはありません。稼いでいるのは、AIを"使う人"です。この記事は、ChatGPTのようなAIを使って、実際に副業ライティングの案件を受注し、納品まで持っていくための具体的な手順をまとめたものです。必要なのは、土日のうち数時間を、案件探しと執筆に充てることだけです。

想定している読者は、次のような会社員です。

- ChatGPTは触ったことがあるが、「それで稼ぐ」ところまでは到達できていない
- 文章を書くこと自体は苦にならないが、プロのライターというほどの自信はない
- 副業に使える時間は平日の隙間時間と土日程度

こういう方に向けて、AIライティング副業が「今」向いている理由と、始め方の全体像をまずお伝えします。

※タイトルの「月3万円」はあくまで一例です。成果は取り組み方や案件の状況によって変わるため、収入を保証するものではありません。

## なぜ今、AIライティング副業が狙い目なのか

副業ライティングという市場自体は以前からありますが、AIの登場で状況が変わりました。

以前は「1文字1円で月2万文字書いて2万円」のような、時間対効果の悪い仕事が中心でした。今は、AIを下書き生成・構成案作成・リサーチ補助として使うことで、同じ文字数を書くのにかかる時間を減らせる可能性があります。うまく使いこなせれば、時給換算での割の良さが変わってくる可能性がある、というのがこの副業の狙い目です。

一方で、「AIに丸投げした文章」はクライアント側にもすぐ見抜かれるようになっています。だからこそ、AIを使いこなして「速いのに質が高い」を実現できる人には、まだチャンスが残っていると考えられます。

## 全体の流れ(5ステップ)

AIライティング副業を始めてから納品するまでの流れは、大きく次の5ステップです。

1. **土台づくり**:自分が書けるジャンルを2〜3個決める(得意分野・興味のある分野)
2. **案件を探す**:クラウドソーシングサービスやSNSで案件情報を探す
3. **提案・受注**:応募文を送り、クライアントとやり取りする
4. **AIを使って執筆**:プロンプトを使って構成・下書きを作り、自分の言葉で仕上げる
5. **納品・継続案件化**:納品後のフィードバック対応、継続依頼につなげる

## よくある失敗

具体的な手順に入る前に、多くの人がつまずくポイントを2つ紹介します。

**失敗1:ジャンルを決めずに手当たり次第に応募する**
得意でも興味もないジャンルの案件に応募すると、AIを使っても執筆に時間がかかり、質も上がりにくくなります。最初は狭くても、自分が書きやすいジャンルに絞るほうが結果的に早く実績が作れます。

**失敗2:AIの出力をそのまま納品する**
AIが作った文章をほぼそのまま提出すると、クライアントに「AI感」を見抜かれ、継続依頼につながりません。AIは下書き・構成の補助として使い、最終的な言葉選びや事例の当てはめは自分で行う必要があります。

ここまでが無料で読める範囲の全体像です。ここから先は「具体的にどんなプロンプトを使うのか」「どうやって案件を見つけて、どんな文面で応募するのか」「単価をどう上げていくのか」という、実際に手を動かすための中身に入っていきます。

## 実際に使うプロンプト例

以下のプロンプト内の【 】部分は、実際に受注した案件の内容に合わせてご自身で書き換えてご利用ください。

### 構成案作成プロンプト

```
あなたは編集者です。以下のテーマで、読者が知りたい順に構成案(見出しレベル)を作ってください。
テーマ:【クライアントから指定されたテーマ】
想定読者:【誰向けか】
文字数:【指定文字数】
```

### 下書き生成プロンプト

```
以下の見出しに沿って、下書きを作成してください。
- 専門用語には簡単な説明を添える
- 一文を長くしすぎない
- 抽象的な精神論ではなく具体例を入れる
見出し:【構成案の見出し】
```

### リサーチ補助プロンプト(執筆前の下調べ用)

```
【テーマ】について、記事を書く前に押さえておくべき論点を5つ挙げてください。
それぞれについて、読者が誤解しやすいポイントがあれば併せて指摘してください。
```

### SEO記事向けプロンプト

```
以下のキーワードで検索する読者が知りたいことを想定し、見出し構成案を作ってください。
キーワード:【対策キーワード】
競合記事によくある構成の弱点があれば、それを埋める見出しも加えてください。
```

### SNS運用代行向けプロンプト(投稿文の下書き)

```
以下のテーマで、Xに投稿する文章の下書きを3パターン作ってください。
- 1つ目:問いかけ型
- 2つ目:結論先出し型
- 3つ目:体験談風
テーマ:【投稿したい内容】
文字数:全角120字以内
```

### 修正指示プロンプト(クライアントからの修正依頼への対応)

```
以下の修正依頼を踏まえて、元の文章を書き直してください。
修正依頼の意図を汲み取り、指摘されていない箇所は変えすぎないようにしてください。
元の文章:【該当箇所】
修正依頼:【クライアントからの指摘内容】
```

これらの出力はあくまで「たたき台」です。事実確認が必要な数値・固有名詞は必ず自分で裏取りし、文末表現やエピソードは自分の言葉に書き直してください。

## 案件の探し方・応募文テンプレート

案件は、大きく分けて「クラウドソーシングサービス」と「SNS上の募集投稿」の2つの経路から探せます。

**クラウドソーシングサービス**
クラウドワークス、ランサーズ、ココナラなどに登録し、「ライティング」「記事作成」「SNS運用代行」などのカテゴリから、自分が書けそうなジャンルの案件を探します。検索窓では、ジャンル名(例:「美容 ライティング」「不動産 記事作成」)で絞り込むと、興味のある分野の案件が見つけやすくなります。

**SNS(X)上の募集投稿**
Xで「#ライター募集」「#Webライター募集」「#SNS運用代行 募集」などのハッシュタグを検索すると、個人事業主や小規模事業者からの直接募集が見つかります。クラウドソーシング経由より単価交渉の余地がある一方、やり取りの信頼性は自分で見極める必要があります。

応募時は、次の3点を簡潔に伝えることを意識してください。

1. 案件のテーマに関連する経験・知識(あれば)
2. 対応可能な文字数・納期の目安
3. AIを活用しつつ、最終的な品質は自分で担保している旨

### 応募文テンプレート例(実績がまだない場合)

```
はじめまして。【ジャンル】に関心があり、貴社の募集を拝見しご応募いたしました。
これまで【関連する経験や興味を持ったきっかけ】があり、読者にとってわかりやすい記事を書くことを心がけています。
納期は【目安】、文字数は【目安】で対応可能です。まずは一度、簡単な構成案からご相談させていただければ幸いです。
```

### 応募文テンプレート例(実績が2〜3件できた場合)

```
はじめまして。【ジャンル】の記事作成を承っております【氏名/屋号】と申します。
これまで【ジャンル】案件を【件数】件、文字数【目安】程度で対応してまいりました(直近の実績:【記事タイトルや簡単な概要】)。
納期は【目安】、文字数は【目安】で対応可能です。構成案を先にご確認いただく形での進行を提案いたします。
```

※【 】の部分は、ご自身の状況に合わせて書き換えてご使用ください。

## 単価の上げ方

副業ライティングの相場は文字単価0.5円〜3円程度と幅があります(※一般的な相場感に基づく参考値で、案件やクライアントにより変動します)。目安として次のような段階を意識すると進めやすくなります。

- **1〜3件目(実績作り期)**:文字単価0.5〜1円程度。相場よりやや低くても、実績とレビューを優先する
- **4〜10件目(実績提示期)**:文字単価1〜1.5円程度。応募文に「これまでの実績(タイトル・文字数・ジャンル)」を添えられるようになった段階で、単価交渉を始める
- **10件以降(専門特化期)**:文字単価1.5円〜。特定ジャンル(例:SNS運用代行、SEO記事など)に特化し、「この分野ならこの人」というポジションを取れた案件から単価を上げる

そのほか、単価交渉を通しやすくするために意識したい点です。

- 納品時に「なぜこの構成にしたか」を一言添え、思考プロセスが見えるようにする
- 修正対応を丁寧に行い、次回依頼のハードルを下げる
- 単価交渉は「値上げしたい」ではなく「継続的に質を上げていくための提案」として伝える
