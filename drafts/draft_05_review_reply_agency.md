# ChatGPTで口コミ返信を代行する。会社員が土日だけで始める「レビュー返信代行」副業の教科書

---

## はじめに

Googleマップでお店を検索したとき、口コミへの返信が一件もない店と、丁寧に返信が並んでいる店、どちらを選びたくなるでしょうか。多くの人が後者を選ぶはずなのに、実際には「返信したほうがいいのはわかっているが、手が回っていない」という店舗オーナーが少なくありません。

正直に言うと、口コミ返信代行というと「炎上対応の専門家でないとできない」と思われがちです。ですが実際に店舗側が困っているのは、炎上級のクレーム対応よりも、日々たまっていく星3〜5の口コミに、一件ずつ丁寧な返信を書く時間が取れない、という地味な部分であることが少なくありません。この記事は、AIを使って口コミ返信の下書きを作り、店舗の状況に合わせて仕上げる形で、口コミ返信代行を副業として請け負うための考え方と手順をまとめたものです。

想定している読者は、次のような会社員です。

- 接客業の経験はなくても、丁寧な言葉選びを考えるのは苦にならない
- ライティングやSNS運用代行に加えて、もう一つ小さな武器を持ちたい
- 副業に使える時間は平日の隙間時間と土日程度

※タイトルの内容は取り組み方の一例です。案件の獲得や収入を保証するものではありません。

## なぜ今、「口コミ返信」だけでも副業になりうるのか

Googleビジネスプロフィールをはじめとする口コミ・レビューの仕組みは、多くの個人店・小規模事業者にとって「集客に直結するとわかっているが、日々の業務に追われて後回しになりがちな」領域です。特に美容室・飲食店・整体院のような、オーナー自身が現場に立っている業種では、口コミが来るたびに目を通してはいても、返信文を考える時間まではなかなか確保できない、という声が見られます。実際、口コミへの返信の有無は、来店を検討している人が店を比較する際の判断材料の一つになっていると一般的に言われています。

ここに、口コミへの返信文だけを請け負う余地があります。接客や商品そのものへの対応は店舗側が行い、「もらった口コミに、どんな言葉で返すか」という文章部分だけを外部に依頼する、という分業です。AIを使えば、星の数や口コミの内容に応じた返信の下書き自体は短時間で複数パターン作れるため、ゼロから毎回考えるより時間を圧縮できる可能性があります。

一方で、AIがそのまま出す返信文は、どの店にも当てはまるような定型文になりがちで、その店ならではの雰囲気や、口コミの具体的な内容への言及が抜けやすくなります。だからこそ、口コミの中身を読み込んで店の個性に合わせて調整できる人には、まだ入り込む余地があると考えられます。

## 全体の流れ(5ステップ)

口コミ返信代行の副業を始めてから案件をこなせるようになるまでの流れは、大きく次の5ステップです。

1. **対象業種を絞る**:美容室・飲食店・整体院など、自分が理解しやすい業種を1〜2つ選ぶ
2. **返信の型を知る**:星の数・内容別に、返信で押さえるべき基本の型を把握する
3. **AIで下書きを量産**:プロンプトを使って星別・状況別の返信下書きを複数パターン作る
4. **店舗の言葉に仕上げる**:定型文を、その店ならではの言葉・事実関係に置き換える
5. **提案・納品・運用**:試作返信を見せて提案し、納品後も新着口コミへの継続対応につなげる

## よくある失敗

具体的な手順に入る前に、つまずきやすいポイントを2つ紹介します。

**失敗1:店舗の確認を取らずに返信文を決めてしまう**
口コミの中には、価格・味・接客対応など事実関係に関わる指摘が含まれることがあります。代行者の想像だけで「対応いたします」などと返信すると、実際の店舗の方針と食い違う約束をしてしまう恐れがあります。返信内容は、特に事実関係やお詫び・改善に触れる部分について、必ず店舗側の確認を経てから投稿することが前提になります。

**失敗2:AIの返信文をそのまま貼り付けてしまう**
AIが作った返信文をそのまま使うと、どの口コミに対しても同じような言い回しになり、口コミを書いた本人からも「読んでもらえていない」と感じられやすくなります。下書きは「たたき台」として使い、口コミの具体的な内容(触れられていたメニュー名やスタッフの対応など)に一言でも言及する一手間が必要です。

ここまでが無料で読める範囲の全体像です。ここから先は、実際に使える星別・状況別の返信プロンプトと返信例、案件の探し方・提案文、運用時に気をつけたいポイント、単価の考え方について、具体的な中身に入っていきます。

## 星の数・状況別の返信プロンプト

以下のプロンプト内の【 】部分は、実際の口コミ・店舗の内容に合わせてご自身で書き換えてご利用ください。返信サンプルはあくまで型のイメージをつかむための架空の例です。実際の返信では、口コミに書かれた固有の内容(メニュー名・接客したスタッフなど)に必ず触れるようにしてください。

### パターン1:星5・好意的な口コミへの返信

```
以下の口コミに対する返信文を作ってください。
口コミに書かれている具体的な内容(メニュー・スタッフ対応など)に一言触れ、
再来店につながる一言を添えてください。堅すぎず、親しみのあるトーンにしてください。
業種:【美容室/飲食店/整体院などの業種】
口コミ内容:【実際の口コミ本文】
店の特徴:【強み・こだわり】
```

**返信サンプル(架空の例・美容室)**
> この度はご来店いただき、ありがとうございました。カットの仕上がりを気に入っていただけたとのこと、大変嬉しく思います。担当スタッフにもお伝えいたします。次回のご来店も、スタッフ一同心よりお待ちしております。

### パターン2:星3〜4・惜しい点も書かれている口コミへの返信

```
以下の口コミに対する返信文を作ってください。
良かった点への感謝と、惜しいと感じられた点への言及をバランスよく含め、
今後の改善に活かす姿勢が伝わる一言を添えてください。
業種:【業種】
口コミ内容:【実際の口コミ本文(良い点と気になる点の両方)】
店の特徴:【強み・こだわり】
```

**返信サンプル(架空の例・飲食店)**
> ご来店ありがとうございました。お料理をお楽しみいただけたとのこと、嬉しく拝見しました。一方で、お待たせする時間が長くなってしまった点、大変申し訳ございませんでした。ご案内の流れを見直し、次回はより快適にお過ごしいただけるよう努めてまいります。

### パターン3:星1〜2・不満が明確な口コミへの返信

```
以下の口コミに対する返信文を作ってください。
まず起きたことへのお詫びを述べ、事実関係を断定せず、
個別に状況を確認したい旨を伝えて、直接連絡できる窓口へ案内する形にしてください。
店舗側でまだ事実確認が取れていない前提で、断定的な表現は避けてください。
業種:【業種】
口コミ内容:【実際の口コミ本文】
問い合わせ窓口:【電話番号・メールアドレスなど】
```

**返信サンプル(架空の例・整体院)**
> この度はご不快な思いをさせてしまい、申し訳ございませんでした。いただいた内容について、当院内で状況を確認させていただきたく存じます。よろしければ【問い合わせ窓口】までご連絡いただけますと、詳しくお話を伺えれば幸いです。

### パターン4:事実と異なる可能性がある口コミへの返信

```
以下の口コミに対する返信文を作ってください。
口コミの内容が店舗側の記録・認識と食い違っている可能性がある場合を想定し、
相手を否定する強い言い方は避けつつ、事実関係を確認したい旨を丁寧に伝える返信にしてください。
業種:【業種】
口コミ内容:【実際の口コミ本文】
店舗側の認識:【店舗から共有された事実関係】
```

**返信サンプル(架空の例・美容室)**
> ご意見をいただきありがとうございます。いただいた内容と当店の記録に一部相違があるようでしたので、よろしければ一度詳しい状況をお聞かせいただけますでしょうか。改めて【問い合わせ窓口】までご連絡いただけますと幸いです。

### パターン5:複数の口コミをまとめて処理したいときのプロンプト

```
以下は、同じ店舗に寄せられた複数の口コミです。
それぞれの口コミに対して、内容に応じた返信文を1件ずつ作ってください。
星5は感謝と一言のプラスアルファ、星3〜4は感謝と改善への言及、
星1〜2はお詫びと個別確認への案内、という書き分けをしてください。
業種:【業種】
口コミ一覧:
1.【口コミ本文1】
2.【口コミ本文2】
3.【口コミ本文3】
```

これらの返信文はあくまで「たたき台」です。特に低評価・クレーム系の口コミへの返信は、事実関係を断定せず、必ず店舗側の確認・承認を経てから投稿するようにしてください。

## 低評価・クレーム系口コミに返信するときの注意点

低評価の口コミは、代行者にとって一番気を使う場面です。次の点を押さえておくと、店舗側とのトラブルを避けやすくなります。

- **事実関係を代行者側で決めつけない**:口コミの内容が事実かどうかは、店舗側にしかわかりません。返信文では断定を避け、「状況を確認させてください」という姿勢にとどめます
- **謝罪と非を認める発言を混同しない**:不快な思いをさせたことへのお詫びと、「こちらの過失です」という事実の承認は別物です。後者を代行者の判断で書かないようにします
- **個人情報・具体的すぎる情報を返信に書かない**:予約日時や個人が特定されうる情報を公開の返信欄に書くのは避け、詳細は個別窓口でのやり取りに誘導します
- **返信前に必ず店舗側の確認を挟む工程を作る**:特に低評価の返信は、下書きをチェックリストとともに店舗側へ送り、承認を得てから投稿する運用にしておくと安心です

## 案件の探し方・提案文テンプレート

口コミ返信代行の案件は、大きく分けて「クラウドソーシング」と「地域の店舗への直接提案」の2つの経路があります。

**クラウドソーシング**
クラウドワークス、ランサーズなどで「口コミ返信」「レビュー返信」「Googleビジネスプロフィール運用」といったキーワードで検索すると、返信文の作成のみを募集している案件が見つかることがあります。募集内容をよく読み、返信文の作成だけか、口コミの監視・レポートまで含むかを事前に確認してください。

**地域の店舗への直接提案**
Googleマップ上で口コミへの返信が止まっている、あるいは一切返信をしていない地域の店舗に、直接提案する方法もあります。実際の口コミページを見て、返信があるとどう印象が変わりそうかを具体的に伝えることが、提案の説得力につながります。

### 提案文テンプレート例(実績がまだない場合)

```
はじめまして。【業種】の口コミ返信文作成のご提案でご連絡いたしました。
貴店のGoogleマップの口コミを拝見し、【良い点を一言】と感じました。
口コミへの返信文の作成でお力になれればと考えております。
返信内容は毎回貴店にご確認いただいたうえで投稿する形を想定しております。
まずは無料で1〜2件、試作の返信文をお見せすることもできますので、よろしければご検討ください。
```

### 提案文テンプレート例(実績が数件できた場合)

```
口コミ返信文の作成を承っております【氏名/屋号】と申します。
これまで【業種】の口コミ返信を【件数】件担当し、返信内容は毎回事前確認をいただく形で運用しております。
貴店のGoogleマップを拝見し、【良い点・改善できそうな点】と感じ、ご連絡いたしました。
月〇件の口コミ返信対応という形でのご相談も可能ですので、よろしければご検討ください。
```

提案の際は、いきなり売り込むのではなく、「無料で1〜2件サンプルを見せる」など、店舗側が判断しやすい材料を示すと、検討してもらいやすくなります。ただしサンプルを何件も無償で作り続けることは避け、最初の1〜2件程度にとどめておくのが現実的です。

## 代行を引き受ける際に必ず確認しておきたい運用ルール

口コミ返信代行は、店舗の看板を背負って発信する仕事でもあります。案件を引き受ける前に、次の点を店舗側とすり合わせておくことをおすすめします。

- **返信の投稿権限は店舗側の管理下に置く**:Googleビジネスプロフィールなどの管理者権限は、店舗のオーナー・担当者から正式に付与してもらう形にし、代行者が店舗になりすまして無断で操作しない
- **返信文は投稿前に店舗側の確認を経る**:特に低評価・事実関係に触れる返信は、下書きの段階で店舗側のチェックを必ず挟む
- **対応範囲を契約時に明確にする**:返信文の作成のみか、投稿作業まで含むか、対応する口コミの件数や頻度を事前に合意しておく
- **虚偽の内容を書かない**:実際にはなかった対応を「すでに改善しました」のように書かない。事実確認が取れていない内容は断定表現を避ける

これらは店舗側との信頼関係を保つためだけでなく、代行者自身が思わぬトラブルに巻き込まれないためにも重要な確認事項です。

## 単価の考え方

口コミ返信代行の相場は、対応件数・確認フローの手間・投稿作業の有無によって幅があります(※一般的な相場感に基づく参考値で、案件により変動します)。目安として次のような段階を意識すると進めやすくなります。

- **実績作り期**:月数件〜10件程度の返信文作成を、相場よりやや低めの単価で引き受け、店舗側の確認フローに慣れる
- **実績提示期**:対応してきた件数・業種を提案文に添えられるようになった段階で、月契約(月〇件〇〇円)の形を提案する
- **専門特化期**:特定業種(美容室専門、飲食店専門など)に絞り、その業種特有の口コミの傾向・返信の型を増やすことで、単価交渉の材料を厚くする

単価交渉を通しやすくするために、次の点も意識してください。

- 低評価口コミへの対応実績(件数・トラブルなく収めた経験)を、守秘義務に配慮した範囲で伝える
- 修正依頼・確認のやり取りには、店舗側の意図を汲み取ったうえで丁寧に対応する
- 値上げの相談は、対応件数や運用実績が見えてきたタイミングで、「継続的に質を上げるための提案」として伝える
