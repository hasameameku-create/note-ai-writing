# ChatGPTで「問い合わせが増える」物件紹介文に変える。会社員が土日だけで始める「賃貸物件紹介文代行」副業の教科書

## はじめに

賃貸物件のポータルサイトを見ていて、間取り図や写真は悪くないのに、紹介文が「駅近・南向き・収納多数」のような単語の羅列だけで終わっている物件ページを見かけたことはないでしょうか。仲介会社の担当者が悪いわけではなく、日々の内見対応・契約手続き・電話対応に追われていて、1件1件の紹介文まで丁寧に書く時間が取りにくい、というのが実情であることが少なくありません。

正直に言うと、不動産ライティングの代行というと「宅建士の資格や不動産の専門知識が必要」というイメージを持たれがちです。ですが実際に仲介会社の担当者が困っているのは、専門知識よりも、「同じような間取りの物件を、毎回どう書き分ければいいかわからない」という、もっと手前の部分であることが少なくありません。この記事は、AIを使って賃貸物件の紹介文の下書きを作り、仲介会社から確認を取った事実で仕上げる形で、物件紹介文の作成代行を副業として請け負うための考え方と手順をまとめたものです。

想定している読者は、次のような会社員です。

- 宅建士などの不動産関連資格はなくても、物件情報を整理して言葉にするのは苦にならない
- ライティングやSNS運用代行に加えて、もう一つ別の切り口の副業を持ちたい
- 副業に使える時間は平日の隙間時間と土日程度

※タイトルの内容は取り組み方の一例です。案件の獲得や収入を保証するものではありません。

## なぜ今、「賃貸物件の紹介文」だけでも副業になりうるのか

賃貸物件のポータルサイトには、1つの仲介会社だけで数十件〜数百件の物件が掲載されていることも珍しくありません。担当者は日々、新規物件の登録・写真撮影・内見対応・契約書類の作成と並行して紹介文も書く必要があるため、忙しい時期ほど紹介文が「設備の箇条書き」だけで済まされ、その物件ならではの魅力が伝わらないまま掲載されているケースが見られます。

ここに、紹介文の文章部分だけを請け負う余地があります。物件情報の入力・内見対応・契約業務は仲介会社側が行い、「掲載されている物件情報をもとに、魅力が伝わる文章に仕上げる」という部分だけを外部に依頼する、という分業です。AIを使えば、間取り・設備・周辺環境といった情報を整理したうえで、紹介文の下書き自体は短時間で複数パターン作れるため、ゼロから毎回考えるより時間を圧縮できる可能性があります。

一方で、AIがそのまま出す紹介文は、どの物件にも当てはまるような一般的な言い回しになりがちで、その物件ならではの特徴(眺望、周辺の生活動線、部屋の使い方のイメージなど)が抜けやすくなります。加えて不動産の紹介文には、実際の物件と異なる印象を与えてはいけないという特有の注意点もあります。だからこそ、仲介会社にヒアリングし、確認が取れた事実だけを丁寧に文章へ落とし込める人には、まだ入り込む余地があると考えられます。

## 全体の流れ(5ステップ)

賃貸物件紹介文代行の副業を始めてから案件をこなせるようになるまでの流れは、大きく次の5ステップです。

1. **対象物件タイプを絞る**:単身向け・ファミリー向け・デザイナーズ物件など、自分が理解しやすいタイプを1〜2つ選ぶ
2. **紹介文の型を知る**:反響につながりやすい賃貸物件紹介文に共通する基本の構成要素を把握する
3. **AIで下書きを量産**:プロンプトを使って物件タイプ別・ターゲット別の紹介文下書きを複数パターン作る
4. **仲介会社の確認事実に仕上げる**:一般論を、その物件ならではの確認済みの事実に置き換える
5. **提案・納品・改善**:試作の紹介文を見せて提案し、問い合わせ数の変化を聞きながら次の紹介文に活かす

## よくある失敗

具体的な手順に入る前に、つまずきやすいポイントを2つ紹介します。

**失敗1:確認が取れていない数値・条件を想像で埋めてしまう**
専有面積、築年数、駅からの徒歩分数、家賃に含まれる設備の範囲などは、代行者が「だいたいこれくらいだろう」と想像で補うと、実際の物件情報と食い違う紹介文になりかねません。不動産広告には、実際のものより著しく優良・有利であるかのように見せる表示を禁じる「おとり広告」規制の考え方があるとされており、代行者が確認不足のまま書いた一文が仲介会社の広告上のリスクになりかねません。数値・条件に関わる部分は、必ず仲介会社側から提供された情報のみを使うことが前提になります。

**失敗2:AIの出力をそのまま貼り付けてしまう**
AIが作った紹介文をそのまま使うと、どの物件ページを読んでも似たような言い回しになり、その物件ならではの魅力が伝わりにくくなります。下書きは「たたき台」として使い、周辺の生活動線や部屋の使い方のイメージなど、その物件ならではの情報を一つでも加える一手間が必要です。

ここまでが無料で読める範囲の全体像です。ここから先は、実際に使える物件タイプ別・ターゲット別の紹介文プロンプトと文例、不動産広告で気をつけたい注意点、案件の探し方・提案文、単価の考え方について、具体的な中身に入っていきます。

## 物件タイプ別・ターゲット別の紹介文プロンプト

以下のプロンプト内の【 】部分は、実際に仲介会社から提供された物件情報に合わせてご自身で書き換えてご利用ください。文例サンプルはあくまで型のイメージをつかむための架空の例です。実際の紹介文では、仲介会社から確認が取れた事実(専有面積・築年数・設備・家賃・駅からの徒歩分数など)のみを反映してください。

### パターン1:基本の物件紹介文(単身向け)

```
以下の物件情報をもとに、賃貸ポータルサイトに掲載する紹介文を
300字程度で作成してください。設備の羅列で終わらせず、
一人暮らしをする人がその部屋でどう過ごせそうかが
イメージできる言葉で説明してください。実際の物件情報にない
表現(断定的な「絶対」「必ず」等を含む)は使わないでください。
間取り・専有面積:【仲介会社から確認した情報】
築年数・駅からの徒歩分数:【仲介会社から確認した情報】
設備:【仲介会社から確認した情報】
周辺環境:【仲介会社から確認した情報】
```

**紹介文サンプル(架空の例・1K、駅徒歩8分)**
> 駅から歩いて8分、コンビニとスーパーが道すがらにある立地です。室内は独立洗面台とバス・トイレ別の仕様で、朝の身支度がしやすい間取りになっています。収納は腰高までのクローゼットが1か所あり、キャリーケースを立てて収納することも可能です。

### パターン2:ファミリー向けに書き分けるプロンプト

```
以下の物件情報をもとに、ファミリー層が検討しやすい紹介文を
300字程度で作成してください。間取りの使い方のイメージ、
周辺の教育・生活環境について、確認が取れている情報のみで
触れてください。確認が取れていない周辺施設については、
書かずに保留にしてください。
間取り・専有面積:【仲介会社から確認した情報】
周辺の教育・生活環境(確認済みのみ):【仲介会社から確認した情報】
設備:【仲介会社から確認した情報】
```

**紹介文サンプル(架空の例・3LDK)**
> 各居室に収納があり、成長に合わせて子ども部屋の使い方を変えやすい3LDKです。キッチンは対面式のため、リビングで過ごす家族の様子を見ながら家事ができます。周辺の教育施設については、仲介会社までお問い合わせください。

### パターン3:反響が薄い紹介文をリライトするプロンプト

```
以下は現在掲載中の物件紹介文です。閲覧はあるものの
問い合わせにつながりにくいという相談を受けています。
改善点を3つ挙げたうえで、リライト後の紹介文を作成してください。
抽象的な表現(「魅力的な物件です」等)は、具体的な言葉に
置き換えてください。ただし元の情報にない事実は加えないでください。
現在の紹介文:【既存の紹介文】
物件情報:【仲介会社から確認した情報】
```

**紹介文サンプル(架空の例・築浅ワンルーム)**
> 改善点:①「魅力的な物件です」が抽象的で、何が魅力かが伝わらない ②収納の具体的なイメージがなく、荷物が収まるか想像しにくい ③生活動線に触れておらず、日常の使い勝手が伝わらない
> リライト後:「築2年、室内はモニター付きインターホンとオートロックを備えています。玄関からキッチンまでの動線に姿見スペースがあり、外出前の身支度もしやすい配置です。」

### パターン4:デザイナーズ・こだわり物件向けの紹介文プロンプト

```
以下の物件情報をもとに、デザイン性・こだわりのある設備を
持つ物件の紹介文を300字程度で作成してください。
デザイン面の特徴を、専門用語を使いすぎずに説明してください。
確認が取れていない設計意図や建築士の意図については、
推測で書かずに保留にしてください。
物件の特徴:【仲介会社から確認した情報】
設備・仕様:【仲介会社から確認した情報】
```

**紹介文サンプル(架空の例・ロフト付き物件)**
> 天井高のある居室に、ロフトスペースを備えた物件です。ロフト部分は収納として使うほか、在宅ワーク用のスペースとして区切って使うことも考えられる広さがあります。窓は道路側ではなく中庭側に配置されており、室内の明るさと視線の抜けを両立させた作りです。

### パターン5:プラットフォームごとの文字数・雰囲気に合わせて調整するプロンプト

```
以下の物件紹介文を、指定したプラットフォーム向けに調整してください。
文字数の上限と、そのプラットフォームでよく読まれる雰囲気
(簡潔な箇条書き寄り/ていねいな説明文 等)に合わせて
書き直してください。ただし内容の事実関係は変えないでください。
元の紹介文:【パターン1〜4で作った紹介文】
プラットフォーム名:【SUUMO/at home/自社サイト など】
文字数上限:【プラットフォームの入力上限】
雰囲気:【簡潔/ていねい など】
```

**紹介文サンプル(架空の例・文字数を100字程度に圧縮する調整)**
> 駅徒歩8分、独立洗面台・バストイレ別の1K。コンビニ・スーパーが道すがらにあり、通勤前後の買い物もしやすい立地です。

これらの文章はあくまで「たたき台」です。特に専有面積・築年数・家賃・設備の有無・駅からの徒歩分数に関わる部分は、仲介会社側から確認が取れた内容のみを反映し、確認が取れていない項目は断定せずに保留にしてください。

## 不動産広告で必ず気をつけたい注意点

不動産の広告表示には、一般的な商品・サービスの説明文以上に気をつけるべき点があります。代行者として、次の点は特に意識してください。

- **実際の物件情報と異なる、著しく優良・有利であるかのような表示をしない**:いわゆる「おとり広告」的な誇張表示は避け、確認できた事実のみを書く
- **専有面積・築年数・駅からの徒歩分数などの数値は、代行者の推測で書かない**:必ず仲介会社側から提供された数値をそのまま使う
- **「絶対」「必ず」など、住み心地や資産価値を保証するような断定表現を使わない**:住み心地の感じ方は個人差があるため、断定を避けた表現にとどめる
- **周辺施設(学校・商業施設など)は、仲介会社が確認済みの情報のみを記載する**:代行者が地図アプリ等で見た情報をそのまま断定的に書かない
- **判断に迷う表現・法令に関わりそうな一文は、掲載前に仲介会社自身の確認を挟む**:代行者だけで宅地建物取引業法や景品表示法上の判断をせず、必要であれば仲介会社側の有資格者に最終確認してもらう

これらは入居希望者との信頼関係を保つためだけでなく、代行者自身が思わぬトラブルに巻き込まれないためにも重要な確認事項です。

## 案件の探し方・提案文テンプレート

賃貸物件紹介文代行の案件は、大きく分けて「クラウドソーシング」と「地域の仲介会社への直接提案」の2つの経路があります。

**クラウドソーシング**
クラウドワークス、ランサーズなどで「不動産 紹介文」「賃貸 物件紹介文 作成」といったキーワードで検索すると、文章作成のみを募集している案件が見つかることがあります。募集内容をよく読み、文章作成だけか、物件情報の入力作業や写真加工まで含むかを事前に確認してください。

**地域の仲介会社への直接提案**
SUUMOやat homeなどのポータルサイトで、紹介文が設備の羅列だけで終わっている物件を多く掲載している地域の仲介会社に、直接提案する方法もあります。実際の物件ページを見て、紹介文を改善するとどう印象が変わりそうかを具体的に伝えることが、提案の説得力につながります。

### 提案文テンプレート例(実績がまだない場合)

```
はじめまして。貴社が掲載されている賃貸物件の紹介文作成の
ご提案でご連絡いたしました。
掲載されている物件ページを拝見し、【気づいた点を一言】と
感じました。物件情報の入力や内見対応は貴社にお任せし、
紹介文の文章部分だけお力になれればと考えております。
まずは1件分だけでも無料でお見せすることもできますので、
よろしければご検討ください。
```

### 提案文テンプレート例(実績が数件できた場合)

```
賃貸物件の紹介文作成を承っております【氏名/屋号】と申します。
これまで【物件タイプ】の紹介文を【件数】件担当し、
数値・設備に関わる記載は毎回貴社にご確認いただく形で
運用しております。掲載されている物件ページを拝見し
【気づいた点】と感じ、ご連絡いたしました。
月〇件の紹介文作成という形でのご相談も可能ですので、
よろしければご検討ください。
```

提案の際は、いきなり売り込むのではなく、「1件分だけ無料で見せる」など、仲介会社側が判断しやすい材料を示すと、検討してもらいやすくなります。ただしサンプルを何点も無償で作り続けることは避け、最初の1件程度にとどめておくのが現実的です。

## 単価の考え方

賃貸物件紹介文代行の単価は、対応する物件件数・ヒアリングの手間・写真選定など付随作業の有無によって幅があります(※クラウドソーシングサイトで公開されている募集内容をもとにした参考値で、案件により変動します。簡易なものは1件あたり数百円〜1,000円程度、複数プラットフォーム向けの調整まで含む難易度の高いものは月契約で数千円〜数万円台とされることもあるようです)。目安として次のような段階を意識すると進めやすくなります。

- **実績作り期**:月数件〜10件程度の紹介文作成を、相場よりやや低めの単価で引き受け、仲介会社とのやり取り・確認事項の進め方に慣れる
- **実績提示期**:対応してきた物件タイプ・件数を提案文に添えられるようになった段階で、1件あたりの単価、または月契約(月〇件〇〇円)の形を提案する
- **専門特化期**:特定の物件タイプ(ファミリー向け専門、デザイナーズ物件専門など)に絞り、そのタイプ特有の入居希望者が気にするポイント・紹介文の型を増やすことで、単価交渉の材料を厚くする

単価交渉を通しやすくするために、次の点も意識してください。

- 対応してきた物件タイプ・件数の実績を、守秘義務に配慮した範囲で伝える
- 修正依頼・表現の指摘には、仲介会社の意図を汲み取ったうえで丁寧に対応する
- 値上げの相談は、対応件数や運用実績が見えてきたタイミングで、「問い合わせにつながる紹介文を継続的に作っていくための提案」として伝える
