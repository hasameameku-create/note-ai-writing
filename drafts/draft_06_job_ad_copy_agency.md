# ChatGPTで「応募が来る求人原稿」に変える。会社員が土日だけで始める「求人原稿・採用ページ代行」副業の教科書

---

## はじめに

求人サイトを見ていて、「仕事内容:接客・レジ業務。やる気のある方歓迎」のような、どの店にも当てはまりそうな求人原稿を目にしたことはないでしょうか。書いている店舗側も、決して手を抜いているわけではなく、日々の業務に追われて求人原稿まで手が回らない、というのが実情であることが少なくありません。

正直に言うと、求人原稿の代行というと「採用のプロでないとできない」と思われがちです。ですが実際に中小の店舗・事業所が困っているのは、採用戦略そのものよりも、「求人サイトの入力フォームを、どんな言葉で埋めればいいかわからない」という、もっと手前の部分であることが少なくありません。この記事は、AIを使って求人原稿の下書きを作り、店舗の実情に合わせて仕上げる形で、求人原稿の作成代行を副業として請け負うための考え方と手順をまとめたものです。

想定している読者は、次のような会社員です。

- 採用や人事の実務経験はなくても、人に伝わる言葉を考えるのは苦にならない
- ライティングやSNS運用代行に加えて、もう一つ別の切り口の副業を持ちたい
- 副業に使える時間は平日の隙間時間と土日程度

※タイトルの内容は取り組み方の一例です。案件の獲得や収入を保証するものではありません。

## なぜ今、「求人原稿」だけでも副業になりうるのか

人手不足に悩む個人店・中小事業所にとって、採用は「重要だとわかっているが、専任の担当者を置くほどではない」業務の代表格です。特に飲食店・美容室・介護施設・運送業のような、現場のオーナーや店長が採用も兼務している業種では、求人サイトの原稿を店を開けながら片手間で書くことになりがちで、結果として当たり障りのない内容になりやすい傾向があります。実際、同じ職種・同じ時給でも、原稿の書き方によって応募のしやすさの印象が変わることは、採用や求人広告の分野で一般的に言われています。

ここに、求人原稿の文章部分だけを請け負う余地があります。採用の合否判断や条件交渉は店舗側が行い、「募集要項をどんな言葉で伝えるか」という原稿部分だけを外部に依頼する、という分業です。AIを使えば、職種・条件・アピールポイントを整理したうえで、原稿の下書き自体は短時間で複数パターン作れるため、ゼロから毎回考えるより時間を圧縮できる可能性があります。

一方で、AIがそのまま出す求人文は、どの店にも当てはまるような無難な表現になりがちで、その店ならではの雰囲気や、応募を検討している人が知りたい具体的な情報(働く曜日のイメージ、職場の人数感など)が抜けやすくなります。だからこそ、店舗にヒアリングして原稿に反映できる人には、まだ入り込む余地があると考えられます。

## 全体の流れ(5ステップ)

求人原稿代行の副業を始めてから案件をこなせるようになるまでの流れは、大きく次の5ステップです。

1. **対象業種を絞る**:飲食店・美容室・介護・軽作業など、自分が理解しやすい業種を1〜2つ選ぶ
2. **求人原稿の型を知る**:職種別・媒体別に、押さえるべき基本の構成要素を把握する
3. **AIで下書きを量産**:プロンプトを使って職種別・ターゲット別の原稿下書きを複数パターン作る
4. **店舗の実情に仕上げる**:定型文を、その店の条件・雰囲気・事実関係に置き換える
5. **提案・納品・改善**:試作原稿を見せて提案し、応募状況を聞きながら次の原稿に活かす

## よくある失敗

具体的な手順に入る前に、つまずきやすいポイントを2つ紹介します。

**失敗1:労働条件のヒアリングを済ませずに原稿を仕上げてしまう**
時給・勤務時間・休日といった労働条件は、店舗側の正確な情報がなければ書けません。代行者の想像で「土日休み」「残業なし」などと書いてしまうと、実際の条件と食い違う原稿になり、応募者とのトラブルや店舗側の信用問題につながりかねません。労働条件に関わる部分は、必ず店舗側から確認を取った内容のみを反映することが前提になります。

**失敗2:AIの出力をそのまま貼り付けてしまう**
AIが作った求人文をそのまま使うと、どの店の原稿を読んでも似たような言い回しになり、応募を検討している人にとって「この店で働くイメージ」が湧きにくくなります。下書きは「たたき台」として使い、その店ならではの情報(職場の人数、実際の1日の流れなど)を一つでも加える一手間が必要です。

ここまでが無料で読める範囲の全体像です。ここから先は、実際に使える職種別・ターゲット別の求人原稿プロンプトと文例、案件の探し方・提案文、運用時に気をつけたいポイント、単価の考え方について、具体的な中身に入っていきます。

## 職種別・ターゲット別の求人原稿プロンプト

以下のプロンプト内の【 】部分は、実際の店舗からヒアリングした内容に合わせてご自身で書き換えてご利用ください。原稿サンプルはあくまで型のイメージをつかむための架空の例です。実際の原稿では、店舗から確認が取れた事実(時給・勤務時間・雰囲気など)のみを反映してください。

### パターン1:基本の求人原稿(未経験歓迎の店舗スタッフ向け)

```
以下の情報をもとに、求人サイトに掲載する原稿を作ってください。
未経験者が「自分にもできそう」と感じられるよう、仕事の具体的な内容を
イメージしやすい言葉で説明してください。誇張した表現は避けてください。
職種:【職種名】
時給・給与:【店舗から確認した条件】
勤務時間・曜日:【店舗から確認した条件】
仕事内容:【具体的な業務内容】
職場の雰囲気・特徴:【店舗から聞いた特徴】
```

**原稿サンプル(架空の例・飲食店ホールスタッフ)**
> 「接客が初めてで不安…」という方も大歓迎です。まずは簡単な配膳やドリンク作りから、先輩スタッフが一つずつ教えます。週2日・1日3時間からOKなので、学業やお子さんの送り迎えと両立しながら働いている方が多い職場です。

### パターン2:応募が集まりにくい原稿をリライトするプロンプト

```
以下は現在掲載中の求人原稿です。応募が集まりにくいという相談を受けています。
改善点を3つ挙げたうえで、リライト後の原稿を作成してください。
抽象的な表現(「やる気のある方」等)は、具体的な言葉に置き換えてください。
現在の原稿:【既存の求人原稿】
職種:【職種名】
店舗の特徴・強み:【店舗から聞いた特徴】
```

**原稿サンプル(架空の例・美容室アシスタント)**
> 改善点:①「やる気のある方歓迎」が抽象的で、具体的にどんな1日を過ごすかが伝わらない ②研修体制への言及がなく、未経験者が不安を感じやすい ③職場の人数感がわからず、雰囲気が想像しにくい
> リライト後:「シャンプーやパーマの下準備から少しずつ担当していただきます。スタッフは20〜30代が中心で、週1回の技術研修も行っています。」

### パターン3:ターゲット層別に書き分けるプロンプト

```
以下の職種について、想定するターゲット層別に、原稿の書き出し部分を
3パターン作ってください。それぞれ、そのターゲット層が働くうえで
気にしやすいポイント(両立のしやすさ、体力面、収入面など)に触れてください。
職種:【職種名】
条件:【時給・勤務時間など】
ターゲット層:【主婦(夫)層/学生/シニア層 など】
```

**原稿サンプル(架空の例・軽作業スタッフ、主婦層向けの書き出し)**
> お子さんが学校に行っている間の時間を有効活用したい方へ。9時〜15時の勤務なので、送り迎えの時間にも間に合います。重い荷物を運ぶ作業はほとんどなく、体力に自信がない方でも始めやすい職場です。

### パターン4:求人媒体ごとの文字数・トーンに合わせて調整するプロンプト

```
以下の求人原稿を、指定した媒体向けに調整してください。
文字数の上限と、その媒体でよく読まれるトーン(カジュアル/フォーマル等)に
合わせて書き直してください。
元の原稿:【パターン1〜3で作った原稿】
媒体名:【求人媒体名】
文字数上限:【媒体の入力上限】
トーン:【カジュアル/フォーマルなど、媒体の傾向】
```

**原稿サンプル(架空の例・文字数を200字程度に圧縮する調整)**
> 「未経験でも大丈夫?」という質問、よくいただきます。答えはもちろんYES。先輩が横について一つずつ教えるので、初日から一人で任されることはありません。週2日・3時間〜、シフトは相談OKです。

### パターン5:よくある質問(FAQ)を原稿に追加するプロンプト

```
以下の職種について、応募を検討している人が気にしそうな質問を5つ想定し、
それぞれに対する回答を求人原稿に追加できる形で作成してください。
店舗から確認が取れていない内容は、質問として保留にし、
勝手に回答を作らないでください。
職種:【職種名】
店舗の情報:【店舗からヒアリングした情報】
```

**原稿サンプル(架空の例・介護施設スタッフ)**
> Q. 資格がなくても働けますか? → A. はい、無資格からスタートしたスタッフも複数在籍しています。入職後に資格取得をサポートする制度もあります。
> Q. 夜勤は必須ですか? → A. 勤務形態によって異なりますので、面接時にご希望を伺いながら相談可能です。

これらの原稿はあくまで「たたき台」です。特に労働条件・資格要件・福利厚生に関わる部分は、店舗側から確認が取れた内容のみを反映し、確認が取れていない項目は断定せずに保留にしてください。

## 労働条件を扱う際に必ず気をつけたい注意点

求人原稿は、応募者と店舗との最初の接点であり、実際の労働条件を正しく伝えることが原稿作成の基本ルールとされています。代行者として、次の点は特に意識してください。

- **時給・勤務時間・休日などの条件は、店舗側が確認した内容のみを記載する**:代行者の推測や「相場ではこれくらいだろう」という想像で条件欄を埋めない
- **実際の業務内容と異なる誇張表現を使わない**:「未経験でもすぐに高収入」のように、実態とかけ離れた期待を煽る表現は避ける
- **資格・待遇に関する情報は特に慎重に扱う**:社会保険の有無や資格手当など、金銭・法的な扱いに関わる項目は、店舗側の最終確認を経てから掲載する
- **原稿の最終確認・掲載作業の可否を事前にすり合わせる**:原稿作成のみを請け負うのか、求人サイトへの入力・掲載作業まで含むのかを契約時に明確にする

これらは店舗側との信頼関係を保つためだけでなく、代行者自身が思わぬトラブルに巻き込まれないためにも重要な確認事項です。

## 案件の探し方・提案文テンプレート

求人原稿代行の案件は、大きく分けて「クラウドソーシング」と「地域の店舗への直接提案」の2つの経路があります。

**クラウドソーシング**
クラウドワークス、ランサーズなどで「求人原稿作成」「採用ページ制作」「求人票 ライティング」といったキーワードで検索すると、原稿作成のみを募集している案件が見つかることがあります。募集内容をよく読み、原稿作成だけか、求人サイトへの掲載作業まで含むかを事前に確認してください。

**地域の店舗への直接提案**
求人サイト上で、原稿が簡素だったり長期間更新されていなかったりする地域の店舗に、直接提案する方法もあります。実際の求人ページを見て、原稿を改善するとどう印象が変わりそうかを具体的に伝えることが、提案の説得力につながります。

### 提案文テンプレート例(実績がまだない場合)

```
はじめまして。【業種】の求人原稿作成のご提案でご連絡いたしました。
貴店の求人ページを拝見し、【気づいた点を一言】と感じました。
応募を検討している方に伝わりやすい原稿の作成でお力になれればと考えております。
条件面の記載は毎回貴店にご確認いただいたうえで作成する形を想定しております。
まずは無料で書き出し部分だけでもお見せすることもできますので、よろしければご検討ください。
```

### 提案文テンプレート例(実績が数件できた場合)

```
求人原稿の作成を承っております【氏名/屋号】と申します。
これまで【業種】の求人原稿を【件数】件担当し、条件面は毎回事前確認をいただく形で運用しております。
貴店の求人ページを拝見し、【気づいた点】と感じ、ご連絡いたしました。
月〇件の原稿作成・更新という形でのご相談も可能ですので、よろしければご検討ください。
```

提案の際は、いきなり売り込むのではなく、「書き出し部分だけ無料で見せる」など、店舗側が判断しやすい材料を示すと、検討してもらいやすくなります。ただしサンプルを何件も無償で作り続けることは避け、最初の1件程度にとどめておくのが現実的です。

## 単価の考え方

求人原稿代行の相場は、対応する原稿の本数・ヒアリングの手間・媒体への掲載作業の有無によって幅があります(※一般的な相場感に基づく参考値で、案件により変動します)。目安として次のような段階を意識すると進めやすくなります。

- **実績作り期**:月1〜3本程度の原稿作成を、相場よりやや低めの単価で引き受け、店舗側へのヒアリングの進め方に慣れる
- **実績提示期**:対応してきた業種・本数を提案文に添えられるようになった段階で、1本あたりの単価、または月契約(月〇本〇〇円)の形を提案する
- **専門特化期**:特定業種(飲食店専門、介護施設専門など)に絞り、その業種特有の応募者が気にするポイント・原稿の型を増やすことで、単価交渉の材料を厚くする

単価交渉を通しやすくするために、次の点も意識してください。

- 対応してきた業種・本数の実績を、守秘義務に配慮した範囲で伝える
- 修正依頼・条件変更のやり取りには、店舗側の意図を汲み取ったうえで丁寧に対応する
- 値上げの相談は、対応本数や運用実績が見えてきたタイミングで、「継続的に応募状況を改善していくための提案」として伝える
