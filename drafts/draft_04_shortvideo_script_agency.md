# AIで台本を量産する。会社員が土日だけで始める「ショート動画運用代行」副業の教科書

---

## はじめに

SNS運用代行というと、Xやインスタの文章まわりを思い浮かべる人が多いかもしれません。ですが今、TikTok・Instagramリール・YouTubeショートのような「縦型ショート動画」を始めたいけれど、台本も構成も考える時間がない、という個人店・小規模事業者が増えています。

正直に言うと、ショート動画運用代行というと「撮影・編集までできないと参入できない」と思われがちです。ですが実際に事業者側が困っているのは、撮影よりもむしろ「何を撮ればいいか」「どんな構成にすれば見てもらえるか」という企画・台本の部分であることが少なくありません。この記事は、AIを使って台本・構成案を作り、撮影は依頼主(お店側)に任せる形で、ショート動画の企画・台本づくりを副業として請け負うための考え方と手順をまとめたものです。

想定している読者は、次のような会社員です。

- 動画の撮影・編集スキルはないが、文章や構成を考えるのは苦にならない
- Xのようなテキストの運用代行に加えて、もう一つ武器を持ちたい
- 副業に使える時間は平日の隙間時間と土日程度

※タイトルの内容は取り組み方の一例です。案件の獲得や収入を保証するものではありません。

## なぜ今、「台本づくり」だけでも副業になりうるのか

TikTok・Instagramリール・YouTubeショートは、多くの個人店・小規模事業者にとって「やったほうがいいのはわかっているが、手が回っていない」領域です。特に美容室・飲食店・士業のような、店主やスタッフが日々の業務に追われている業種では、スマホでの撮影自体は難しくなくても、「毎回何を話すか」「どんな構成にすれば最後まで見てもらえるか」を考える時間が確保しにくい、という声が見られます。

ここに、台本・構成づくりだけを請け負う余地があります。撮影・編集は依頼主自身、あるいは別の担当者が行い、「何を、どの順番で話すか」という台本部分だけを外部に依頼する、という分業です。AIを使えば、構成のたたき台自体は短時間で複数パターン作れるため、ゼロから毎回考えるより企画にかかる時間を圧縮できる可能性があります。

一方で、AIがそのまま出す台本は、業種を問わない一般論になりがちで、そのお店ならではの雰囲気や強みが反映されません。だからこそ、依頼主の業種・客層に合わせてAIの出力を調整できる人には、まだ入り込む余地があると考えられます。

## 全体の流れ(5ステップ)

台本づくりの副業を始めてから案件をこなせるようになるまでの流れは、大きく次の5ステップです。

1. **対象業種を絞る**:美容室・飲食店・士業など、自分が理解しやすい業種を1〜2つ選ぶ
2. **型を知る**:ショート動画で反応が取りやすい構成パターンを把握する
3. **AIで台本を量産**:プロンプトを使って構成案・台本の下書きを複数パターン作る
4. **業種・お店に合わせて仕上げる**:一般論をその店ならではの内容に調整する
5. **提案・納品・改善提案**:試作台本を見せて提案し、納品後は反応を踏まえた改善案も添える

## よくある失敗

具体的な手順に入る前に、つまずきやすいポイントを2つ紹介します。

**失敗1:撮影・編集まで自分で抱え込もうとする**
「動画運用代行」という言葉から、撮影や編集まで自分でやらなければと考えて、必要な機材やスキルの準備に時間を使いすぎてしまうケースがあります。まずは台本・構成案の提供だけに範囲を絞ったほうが、副業として始めるハードルは下がります。

**失敗2:AIの台本をそのまま渡してしまう**
AIが作った構成案をそのまま納品すると、どの業種にも当てはまるような一般的な内容になり、依頼主の店の個性が出ません。台本は「たたき台」として使い、依頼主のお店ならではの強み・言葉遣いに置き換える一手間が必要です。

ここまでが無料で読める範囲の全体像です。ここから先は、実際に使える台本構成パターンとプロンプト、業種別の台本例、案件の探し方・提案文、単価の考え方について、具体的な中身に入っていきます。

## 反応が取りやすい台本構成パターン

以下のプロンプト内の【 】部分は、実際の依頼主の業種・内容に合わせてご自身で書き換えてご利用ください。台本サンプルはあくまで型のイメージをつかむための架空の例です。

### パターン1:悩み共感→解決の一言型

```
以下の業種・お店について、視聴者の悩みに共感してから解決の一言を提示する、
30秒程度のショート動画の台本を作ってください。
構成:①冒頭3秒で悩みを一言で言い当てる ②共感を示す ③お店ならではの解決策を一言で提示 ④行動を促す一言
業種:【美容室/飲食店/士業などの業種】
お店の特徴:【強み・こだわり】
```

**台本サンプル(架空の例・美容室)**
> 「くせ毛、朝のセットに30分かかってませんか」
> わかります、それ。
> うちでは、くせを活かすカットを提案しています。
> 気になる方は、プロフィールの予約リンクからどうぞ。

### パターン2:ビフォーアフター型

```
以下の業種について、施術・サービスの「ビフォーアフター」を見せる構成の
ショート動画台本を作ってください。
構成:①ビフォーの状態を見せる ②お店で行った工夫を一言で説明 ③アフターを見せる ④一言コメント
業種:【業種】
サービス内容:【施術・メニューの内容】
```

**台本サンプル(架空の例・飲食店)**
> 仕込み前の状態です。
> 今日はこの食材を、○時間かけて下処理しました。
> できあがりがこちら。
> 手間をかけた分、味の違いを感じてもらえたら嬉しいです。

### パターン3:数字インパクト型

```
以下の業種について、具体的な数字を1つ入れたショート動画台本を作ってください。
数字は誇張せず、依頼主から確認が取れる範囲の情報のみを使ってください。
構成:①数字を冒頭で提示 ②その数字の背景を説明 ③行動を促す一言
業種:【業種】
使いたい数字:【実際にお店側が提供できる数字】
```

**台本サンプル(架空の例・士業)**
> 相談の8割は、実は制度を知らなかっただけ、というケースです。
> 知っているかどうかで結果が変わることは少なくありません。
> まずは一度、状況を整理するところから相談してみませんか。

### パターン4:Q&A型

```
以下の業種について、お客様からよく聞かれる質問に答える形の
ショート動画台本を作ってください。
構成:①質問を提示 ②結論を先に一言で答える ③簡単な補足 ④行動を促す一言
業種:【業種】
よくある質問:【実際にお店が受けている質問】
```

**台本サンプル(架空の例・美容室)**
> 「パーマと縮毛矯正、同時にできますか」
> 結論、順番と期間を空ければ可能です。
> 髪の状態を見ながらご提案しています。
> 気になる方は一度ご相談ください。

### パターン5:舞台裏(あるある)型

```
以下の業種について、お店の日常や準備の様子を見せる「舞台裏」構成の
ショート動画台本を作ってください。
構成:①普段見えない作業風景を見せる ②その作業の意味を一言で説明 ③お店らしい一言で締める
業種:【業種】
見せられる作業内容:【開店準備・仕込み・準備作業など】
```

**台本サンプル(架空の例・飲食店)**
> 開店の2時間前、まだ誰もいない店内です。
> この時間に、今日出す分のスープを仕込んでいます。
> 派手さはないですが、この積み重ねが味になると思っています。

これらの台本はあくまで「たたき台」です。数字や実績に関する内容は必ず依頼主に事実確認を取り、誇張した表現や確認の取れない実績を含めないようにしてください。

## 案件の探し方・提案文テンプレート

台本づくりの案件は、大きく分けて「クラウドソーシング」と「地域の店舗への直接提案」の2つの経路があります。

**クラウドソーシング**
クラウドワークス、ランサーズなどで「SNS運用代行」「動画構成」「台本作成」といったキーワードで検索すると、動画の企画・構成のみを募集している案件が見つかることがあります。募集内容をよく読み、撮影・編集込みか、構成・台本のみかを事前に確認してください。

**地域の店舗への直接提案**
すでにSNSアカウントを持っているが更新が止まっている、あるいはこれから始めたいと考えていそうな地域の店舗に、直接提案する方法もあります。相手のアカウントを実際に見て、良い点と改善余地を具体的に伝えることが、提案の説得力につながります。

### 提案文テンプレート例(実績がまだない場合)

```
はじめまして。【業種】のショート動画企画・台本作成のご提案でご連絡いたしました。
貴店のSNSを拝見し、【良い点を一言】と感じました。
台本・構成案の作成でお力になれればと考えております。
撮影・編集は貴店側で行っていただく形で、台本部分のみお引き受けする形も可能です。
まずは無料で1本、試作の構成案をお見せすることもできますので、よろしければご検討ください。
```

### 提案文テンプレート例(実績が数件できた場合)

```
【業種】向けのショート動画台本作成を承っております【氏名/屋号】と申します。
これまで【業種】の台本作成を【件数】件担当し、投稿後の反応も踏まえた改善提案まで行っております。
貴店のSNSを拝見し、【良い点・改善できそうな点】と感じ、ご連絡いたしました。
月〇本の台本提供という形でのご相談も可能ですので、よろしければご検討ください。
```

提案の際は、いきなり売り込むのではなく、「無料で1本サンプルを見せる」など、依頼主が判断しやすい材料を示すと、検討してもらいやすくなります。ただしサンプルを何本も無償で作り続けることは避け、最初の1〜2本程度にとどめておくのが現実的です。

## 単価の考え方

台本作成のみを請け負う場合の相場は、依頼内容(本数・修正回数・企画の作り込み度合い)によって幅があります(※一般的な相場感に基づく参考値で、案件により変動します)。目安として次のような段階を意識すると進めやすくなります。

- **実績作り期**:月数本の台本提供を、相場よりやや低めの単価で引き受け、投稿後の反応データも一緒に確認させてもらう
- **実績提示期**:過去に作った台本のジャンル・パターン数を提案文に添えられるようになった段階で、月契約(月〇本〇〇円)の形を提案する
- **専門特化期**:特定業種(美容室専門、飲食店専門など)に絞り、その業種向けの構成パターンを増やすことで、単価交渉の材料を厚くする

単価交渉を通しやすくするために、次の点も意識してください。

- 台本だけでなく、投稿後にどのパターンの反応が良かったかを簡単にまとめて共有する
- 修正依頼には、意図を汲み取ったうえで丁寧に対応する
- 値上げの相談は、対応本数や成果が見えてきたタイミングで、「継続的に質を上げるための提案」として伝える
