# ChatGPTで「売れる商品ページ」に変える。会社員が土日だけで始める「EC商品説明文代行」副業の教科書

---

## はじめに

BASEやSTORES、minneのようなプラットフォームで、写真は良いのに説明文が「サイズ:M/カラー:ベージュ」のような箇条書きだけで終わっている商品ページを見かけたことはないでしょうか。作っている本人が悪いわけではなく、商品を作る・仕入れる・発送するだけで手一杯で、説明文まで丁寧に書く余裕がない、というのが実情であることが少なくありません。

正直に言うと、EC商品説明文の代行というと「マーケティングの専門知識がないとできない」と思われがちです。ですが実際に個人ショップのオーナーが困っているのは、高度な戦略よりも、「この商品の良さを、どんな言葉で伝えればいいかわからない」という、もっと手前の部分であることが少なくありません。この記事は、AIを使って商品説明文の下書きを作り、ショップオーナーへのヒアリングをもとに仕上げる形で、EC商品説明文の作成代行を副業として請け負うための考え方と手順をまとめたものです。

想定している読者は、次のような会社員です。

- マーケティングや広告の実務経験はなくても、商品の魅力を言葉にするのは苦にならない
- ライティングやSNS運用代行に加えて、もう一つ別の切り口の副業を持ちたい
- 副業に使える時間は平日の隙間時間と土日程度

※タイトルの内容は取り組み方の一例です。案件の獲得や収入を保証するものではありません。

## なぜ今、「商品説明文」だけでも副業になりうるのか

個人・小規模事業者がBASE、STORES、minne、あるいはInstagramショップ機能などを使って商品を売る形は、この数年で身近なものになりました。ハンドメイド作家や小さな食品・雑貨メーカーにとって、商品ページの説明文は「重要だとわかっているが、写真や商品づくりを優先して後回しになりがちな」業務の代表格です。特に一人、あるいは少人数で運営しているショップでは、説明文がスペック情報の羅列だけになりやすく、その商品ならではの背景やこだわりが伝わらないまま掲載されているケースが見られます。

ここに、商品説明文の文章部分だけを請け負う余地があります。商品づくりや在庫管理はショップ側が行い、「商品の魅力をどんな言葉で伝えるか」という説明文部分だけを外部に依頼する、という分業です。AIを使えば、素材や特徴を整理したうえで、説明文の下書き自体は短時間で複数パターン作れるため、ゼロから毎回考えるより時間を圧縮できる可能性があります。

一方で、AIがそのまま出す商品説明文は、どの商品にも当てはまるような一般的な言い回しになりがちで、その商品ならではの背景(作り手のこだわり、素材の産地、使うシーンのイメージなど)が抜けやすくなります。だからこそ、ショップオーナーにヒアリングして説明文に反映できる人には、まだ入り込む余地があると考えられます。

## 全体の流れ(5ステップ)

EC商品説明文代行の副業を始めてから案件をこなせるようになるまでの流れは、大きく次の5ステップです。

1. **対象ジャンルを絞る**:ハンドメイド雑貨・食品・アパレルなど、自分が理解しやすいジャンルを1〜2つ選ぶ
2. **商品説明文の型を知る**:読まれる商品ページに共通する基本の構成要素を把握する
3. **AIで下書きを量産**:プロンプトを使って商品別・ターゲット別の説明文下書きを複数パターン作る
4. **ショップの実情に仕上げる**:一般論を、その商品・作り手ならではの事実に置き換える
5. **提案・納品・改善**:試作の説明文を見せて提案し、閲覧・購入状況を聞きながら次の説明文に活かす

## よくある失敗

具体的な手順に入る前に、つまずきやすいポイントを2つ紹介します。

**失敗1:効果・効能を裏付けなく断定して書いてしまう**
特に食品・化粧品・健康関連の商品は、「必ず痩せる」「肌が確実に綺麗になる」のような効果を保証する表現や、根拠のない数値を使うと、景品表示法・薬機法などに触れる可能性があります。代行者が良かれと思って盛った表現が、ショップ側の法的リスクになりかねません。効果・効能に関わる表現は、ショップ側が根拠を持って確認できる内容にとどめ、判断に迷う場合は「その表現は避けましょう」と提案することが前提になります。

**失敗2:AIの出力をそのまま貼り付けてしまう**
AIが作った説明文をそのまま使うと、どの商品ページを読んでも似たような言い回しになり、その商品ならではの魅力が伝わりにくくなります。下書きは「たたき台」として使い、作り手のこだわりや素材の背景など、その商品ならではの情報を一つでも加える一手間が必要です。

## ジャンル別・ターゲット別の商品説明文プロンプト

以下のプロンプト内の【 】部分は、実際のショップオーナーからヒアリングした内容に合わせてご自身で書き換えてご利用ください。説明文サンプルはあくまで型のイメージをつかむための架空の例です。実際の説明文では、ショップ側から確認が取れた事実(素材・原材料・製法など)のみを反映してください。

### パターン1:基本の商品説明文(ハンドメイド雑貨向け)

```
以下の情報をもとに、ECサイトに掲載する商品説明文を作ってください。
商品の特徴だけでなく、使うシーンがイメージできる言葉で説明してください。
効果・効能を保証するような表現は避けてください。
商品名:【商品名】
素材・仕様:【店舗から確認した情報】
作り手のこだわり:【店舗から聞いた特徴】
想定される使用シーン:【想定される利用シーン】
価格帯:【店舗から確認した価格】
```

**説明文サンプル(架空の例・ハンドメイドの帆布トートバッグ)**
> 一枚の帆布から、内側の縫い目まで一人で仕立てています。底にマチを持たせているので、A4サイズの書類や折りたたみ傘を入れても型崩れしにくい作りです。普段使いはもちろん、資料を持ち歩く出張バッグとしても使いやすいサイズ感です。

### パターン2:反応が薄い説明文をリライトするプロンプト

```
以下は現在掲載中の商品説明文です。閲覧はあるものの購入につながりにくい
という相談を受けています。改善点を3つ挙げたうえで、リライト後の
説明文を作成してください。抽象的な表現(「こだわりの逸品」等)は、
具体的な言葉に置き換えてください。
現在の説明文:【既存の商品説明文】
商品名:【商品名】
店舗の特徴・強み:【店舗から聞いた特徴】
```

**説明文サンプル(架空の例・自家製ジャム)**
> 改善点:①「こだわりの逸品」が抽象的で、何にこだわっているかが伝わらない ②糖度や甘さの目安がなく、味の想像がしにくい ③食べ方の提案がなく、購入後の使い方がイメージできない
> リライト後:「完熟した果実だけを選び、砂糖控えめで煮詰めています。パンだけでなく、ヨーグルトに混ぜたり、紅茶に溶かしたりする使い方もおすすめです。」

### パターン3:ターゲット層別に書き分けるプロンプト

```
以下の商品について、想定する購入者層別に、説明文の書き出し部分を
3パターン作ってください。それぞれ、その層が購入前に気にしやすい
ポイント(贈り物としての印象、自分用としての使い勝手、価格の納得感など)
に触れてください。
商品名:【商品名】
特徴:【素材・仕様など】
想定される購入者層:【自分用/贈り物用/リピーター など】
```

**説明文サンプル(架空の例・アロマキャンドル、贈り物用の書き出し)**
> 大切な方への贈り物に、香りで気持ちを伝えてみませんか。落ち着いた香りづけで、性別・年代を問わず贈りやすい一品です。箱を開けた瞬間の香り立ちも意識して仕上げています。

### パターン4:プラットフォームごとの文字数・雰囲気に合わせて調整するプロンプト

```
以下の商品説明文を、指定したプラットフォーム向けに調整してください。
文字数の上限と、そのプラットフォームでよく読まれる雰囲気
(カジュアル/ていねい語 等)に合わせて書き直してください。
元の説明文:【パターン1〜3で作った説明文】
プラットフォーム名:【BASE/STORES/minne/Instagramショップ など】
文字数上限:【プラットフォームの入力上限】
雰囲気:【カジュアル/ていねいな接客口調 など】
```

**説明文サンプル(架空の例・文字数を150字程度に圧縮する調整)**
> 「一つひとつ表情が違う」が、この器の魅力です。手のひらに収まるサイズで、普段使いの一枚に。電子レンジ対応なので、忙しい日の食卓にも気軽に使っていただけます。

### パターン5:よくある質問(FAQ)を商品ページに追加するプロンプト

```
以下の商品について、購入を検討している人が気にしそうな質問を5つ想定し、
それぞれに対する回答を商品ページに追加できる形で作成してください。
店舗から確認が取れていない内容は、質問として保留にし、
勝手に回答を作らないでください。
商品名:【商品名】
店舗の情報:【店舗からヒアリングした情報】
```

**説明文サンプル(架空の例・自家製フィナンシェ)**
> Q. 賞味期限はどのくらいですか? → A. 発送日から◯日を目安にしております。詳しくは商品到着後の表示をご確認ください。
> Q. アレルギー表示はありますか? → A. 使用している原材料については商品ページ下部に記載しております。ご不明な点はお問い合わせください。

これらの説明文はあくまで「たたき台」です。特に原材料・アレルギー表示・素材の産地に関わる部分は、店舗側から確認が取れた内容のみを反映し、確認が取れていない項目は断定せずに保留にしてください。

## 効果・効能に関わる表現で必ず気をつけたい注意点

商品説明文は、購入者が商品を判断する最初の材料であり、実際の商品と異なる期待を持たせないことが説明文作成の基本ルールとされています。代行者として、次の点は特に意識してください。

- **健康・美容効果を保証する表現を使わない**:「必ず痩せる」「肌が確実に綺麗になる」のような、効果を断定・保証する表現は避ける(食品表示や化粧品の表現には景品表示法・薬機法などの規制があることを念頭に置く)
- **原材料・アレルギー表示・産地などは、店舗側が確認した内容のみを記載する**:代行者の推測や「おそらくこうだろう」という想像で埋めない
- **実際の商品と異なる誇張表現を使わない**:「業界最高品質」のように、根拠を示せない最上級表現は避ける
- **判断に迷う表現は、掲載前にショップオーナー自身の確認を挟む**:効果・効能や法規制に関わりそうな一文は、代行者だけで判断せず、必要であればショップオーナー側で最終確認してもらう

これらは購入者との信頼関係を保つためだけでなく、代行者自身が思わぬトラブルに巻き込まれないためにも重要な確認事項です。

## 案件の探し方・提案文テンプレート

EC商品説明文代行の案件は、大きく分けて「クラウドソーシング」と「個人ショップへの直接提案」の2つの経路があります。

**クラウドソーシング**
クラウドワークス、ランサーズなどで「商品説明文作成」「ECライティング」「商品ページ 文章」といったキーワードで検索すると、説明文作成のみを募集している案件が見つかることがあります。募集内容をよく読み、説明文作成だけか、写真加工や掲載作業まで含むかを事前に確認してください。

**個人ショップへの直接提案**
BASE、STORES、minneなどで、説明文がスペック情報だけで終わっている個人ショップに、直接提案する方法もあります。実際の商品ページを見て、説明文を改善するとどう印象が変わりそうかを具体的に伝えることが、提案の説得力につながります。

### 提案文テンプレート例(実績がまだない場合)

```
はじめまして。【ジャンル】の商品説明文作成のご提案でご連絡いたしました。
貴店の商品ページを拝見し、【気づいた点を一言】と感じました。
商品の魅力がより伝わる説明文の作成でお力になれればと考えております。
原材料・効果効能に関わる記載は毎回貴店にご確認いただいたうえで
作成する形を想定しております。
まずは無料で1商品分だけでもお見せすることもできますので、
よろしければご検討ください。
```

### 提案文テンプレート例(実績が数件できた場合)

```
商品説明文の作成を承っております【氏名/屋号】と申します。
これまで【ジャンル】の商品説明文を【件数】件担当し、
原材料・効果効能に関わる記載は毎回事前確認をいただく形で運用しております。
貴店の商品ページを拝見し、【気づいた点】と感じ、ご連絡いたしました。
月〇点の説明文作成・リライトという形でのご相談も可能ですので、
よろしければご検討ください。
```

提案の際は、いきなり売り込むのではなく、「1商品分だけ無料で見せる」など、ショップオーナー側が判断しやすい材料を示すと、検討してもらいやすくなります。ただしサンプルを何点も無償で作り続けることは避け、最初の1点程度にとどめておくのが現実的です。

## 単価の考え方

EC商品説明文代行の相場は、対応する商品点数・ヒアリングの手間・写真加工など付随作業の有無によって幅があります(※一般的な相場感に基づく参考値で、案件により変動します)。目安として次のような段階を意識すると進めやすくなります。

- **実績作り期**:月数点〜10点程度の説明文作成を、相場よりやや低めの単価で引き受け、ショップオーナーへのヒアリングの進め方に慣れる
- **実績提示期**:対応してきたジャンル・点数を提案文に添えられるようになった段階で、1点あたりの単価、または月契約(月〇点〇〇円)の形を提案する
- **専門特化期**:特定ジャンル(ハンドメイド雑貨専門、食品専門など)に絞り、そのジャンル特有の購入者が気にするポイント・説明文の型を増やすことで、単価交渉の材料を厚くする

単価交渉を通しやすくするために、次の点も意識してください。

- 対応してきたジャンル・点数の実績を、守秘義務に配慮した範囲で伝える
- 修正依頼・表現の指摘には、ショップオーナーの意図を汲み取ったうえで丁寧に対応する
- 値上げの相談は、対応点数や運用実績が見えてきたタイミングで、「継続的に商品ページを改善していくための提案」として伝える
