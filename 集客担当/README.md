# 集客担当の役割・手順

## 役割

- Xの告知ポスト作成
- プロフィールからnoteへの導線設計

## 手順

1. 告知対象のnote(テーマ・タイトル・価格・ターゲット)を確認する
2. 告知ポスト案を複数(3パターン程度)作る
   - 課題喚起型(悩みへの問いかけから入る)
   - 具体性訴求型(記事の中身を具体的に見せる)
   - 実践者目線型(スタンスを伝える)
3. プロフィール文・固定ポストは、「誰の・どんな悩みを・どう解決する人か」が一目でわかるようにする

## 注意

- 実際にXへ投稿する、プロフィールを変更する場合は、内容を提示しユーザーの承認を得てから行う(自動では実行しない)
- 過度に煽る・誤解を招く告知文は避ける(内容と乖離した期待を煽らない)
- 現状(2026年時点)、Xアカウントは未作成。アカウントができるまでは、告知文の作成・ストックのみ行い、投稿は保留する
