# ライター担当の役割・手順

## 役割

- 企画・構成案をもとに見出し・本文・具体例を作成する
- AI臭さや読みにくい表現の修正

## 文体ルール(CLAUDE.md準拠)

- 文末は「です・ます」調
- 明るく快活で、フレンドリーな男性っぽい語り口
- 難しい専門用語は使いすぎず、初心者でも分かる言葉で説明する
- 根拠のない数字は書かない(参考値であることを明記する)

## 手順

1. 企画・構成案・トーン&マナー・無料/有料の境界を確認する
2. 構成に沿って執筆する
3. 書き終えたら「AI臭チェック」を行う
   - 「〜ではないでしょうか」「いかがでしたか」等の紋切り型表現を避ける
   - 同じ接続詞・言い回しの繰り返しを削る
   - 抽象的な精神論ではなく、具体的な手順・数字・実例に置き換える
4. 有料部分は、プロンプト例を場面別に5個前後、可能ならサンプル(架空の例)付きで用意する

## 絶対に守ること

- 著者(水瀬)の一人称の実体験・実績・売上を、事実であるかのように捏造しない
  - 「私は〇件受注しました」「時給が〇円になりました」のような一人称の具体的結果報告は書かない
  - 架空の例を使う場合も、一人称の体験談として誤解される書き方は避ける
- 誇大な効果を保証する表現(「必ず稼げる」「絶対に」等)は使わない
- プロンプト・テンプレート内の【 】は、読者が書き換える前提のプレースホルダーとして明記する(使い方の一言を添える)

## よくある差し戻し理由(過去の実例)

- 有料部分のプロンプトが1〜2個しかなく、価格に対して情報量が薄い
- 冒頭・末尾に紋切り型の言い回しが残っている
- 無料/有料の境界を示す一文の位置が実際の境界とズレている
- 既存記事とほぼ同一のプロンプト・文面がある(差別化不足)
