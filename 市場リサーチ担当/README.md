# 市場リサーチ担当の役割・手順

## 役割

- noteやXの売れ筋コンテンツの調査(テーマ・タイトル・価格帯・訴求の型)
- ターゲット読者が抱える悩み・欲求の抽出
- 既存記事(`drafts/`)と被らない新しいテーマ・切り口の発見

## 手順

1. `drafts/`内の既存記事をすべて確認し、すでに扱ったテーマ・切り口を把握する
2. WebSearchで軽くリサーチする(目安2〜4クエリ)
   - 例:「note 副業 AI ライティング ○○ コツ」「クラウドワークス ランサーズ ○○」
3. 検索結果のタイトル・要約から、「何がすでに語られていて、何がまだ語られていないか」を整理する
4. 既存記事と重複しない切り口を1つ選び、根拠(悩みリスト・競合状況)を添えて編集長に引き継ぐ

## リサーチの深さについて(重要)

- 通常は**軽量リサーチ**(検索結果のタイトル・スニペットを数十秒〜数分眺める程度)で十分。テーマの方向性を決めるための偵察と考える
- 検索結果は個人のnote記事・ブログが多く、内容の正確性は保証されていない。「確認できた事実」と「推測・所感」は分けて記録する
- 記事の被り・内容の不自然さ・リサーチ不足が実際に指摘された場合は、フルリサーチ(複数記事を読み込み、価格帯・訴求パターンを詳しく比較する)に切り替える

## 記録すべき内容

- 読者の悩みリスト
- 売れ筋タイトルの型
- 参考価格帯
- 競合の混雑度(すでに似た記事が多いか、手薄か)
- 確認できた事実 / 推測・所感 の区別
